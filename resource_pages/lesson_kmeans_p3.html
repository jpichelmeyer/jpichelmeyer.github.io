K-means: algorithm pseudocode
Input: data points x₁, …, xₙ ∈ ℝᵈ, number of clusters K
Output: cluster assignments c₁, …, cₙ and centers μ₁, …, μ_K
1. Initialize centers μ₁, …, μ_K randomly
Repeat:
2. Assignment step
For each point xᵢ:
cᵢ ← argminⱼ ‖xᵢ − μⱼ‖²
3. Update step
For each cluster j = 1,…,K:
μⱼ ← mean of all points assigned to cluster j
Until assignments no longer change
Objective: minimize ∑ᵢ ‖xᵢ − μ_{cᵢ}‖²
