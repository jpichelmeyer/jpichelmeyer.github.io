/*================================================================================

    Information dependency

================================================================================*/

We consider fileChild information dependent on fileParent if 
    CSS     fileChild references a class from fileParent
    JS      fileChild needs to call a function/variable from fileParent

We visualize this with

    fileChild <--- fileParent

There should be only one file that has no children:     v002/index.html
All other files should have EXACTLY one child.
Files may have multiple parents.


Formal syntax/structure for handling information dependency:
    
    ==================================================
    CSS
        ----------------------------------------------
        fileParent (.css)
        ----------------------------------------------
        :root{
        
        }
                
        .my-gen-use-class{
            ...: ....;
            ...: ....;
        }
        
        #my-unique-class{
            ...: ....;
            ...: ....;
        }
        
        ----------------------------------------------
        fileChild (.css)
        ----------------------------------------------
        @import 'rel/path/to/fileParent.css

    ==================================================
    JS
    
        ----------------------------------------------
        fileParent (.js)
        ----------------------------------------------
        const GLOBAL_PARAM = ...
        
        // This is usuable by fileChild
        export function myFunction(params){
            // body logic
        }
        
        // This is NOT usuable by fileChild
        function myOtherFunction(params){
            // body logic
        }
        
        
        ----------------------------------------------
        fileChild (.js)
        ----------------------------------------------
        import * as Boot from './fileParent.js';
        'use strict';
            
    ==================================================
