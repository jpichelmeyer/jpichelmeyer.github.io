Practice Examples

Work out your answers to the following questions on paper, then check your answers below.

  1. 1 Use the Trapezoidal Rule with $n=4$ to approximate $\displaystyle\int_1^2 \frac{1}{x}\,dx$.
  2. 2 Use the Trapezoidal Rule with $n=4$ to approximate $\displaystyle\int_0^4 \sqrt{x}\,dx$.
  3. 3 Use the Trapezoidal Rule with $n=6$ to approximate $\displaystyle\int_0^{\pi} \sin(x)\,dx$.
  4. 4 Use the Trapezoidal Rule with $n=4$ to approximate $\displaystyle\int_0^1 e^{-x^2}\,dx$.
  5. 5 Use the Trapezoidal Rule with $n=4$ to approximate $\displaystyle\int_0^2 x^2\,dx$, then compare it to the exact value.
  6. 6 Use the Trapezoidal Rule with $n=4$ to approximate $\displaystyle\int_0^1 \frac{1}{1+x^2}\,dx$.
  7. 7 Use Simpson's Rule with $n=4$ to approximate $\displaystyle\int_1^2 \frac{1}{x}\,dx$.
  8. 8 Use Simpson's Rule with $n=4$ to approximate $\displaystyle\int_0^4 \sqrt{x}\,dx$.
  9. 9 Use Simpson's Rule with $n=6$ to approximate $\displaystyle\int_0^{\pi} \sin(x)\,dx$.
  10. 10 Use Simpson's Rule with $n=4$ to approximate $\displaystyle\int_0^1 e^{-x^2}\,dx$.
  11. 11 Use Simpson's Rule with $n=4$ to approximate $\displaystyle\int_0^2 x^2\,dx$. Why is this approximation exact?
  12. 12 Use Simpson's Rule with $n=4$ to approximate $\displaystyle\int_0^1 \frac{1}{1+x^2}\,dx$.
  13. 13 For $f(x)=\dfrac1x$ on $[1,2]$, $|f''(x)|\le 2$. How large must $n$ be for the Trapezoidal Rule error to be guaranteed under $0.0001$?
  14. 14 For $f(x)=\dfrac1x$ on $[1,2]$, $|f^{(4)}(x)|\le 24$. How large must (even) $n$ be for the Simpson's Rule error to be guaranteed under $0.0001$?
  15. 15 A car's velocity (m/s) is recorded every second: $v(0)=3,\ v(1)=5,\ v(2)=4,\ v(3)=7,\ v(4)=6$. Use the Trapezoidal Rule to estimate the distance traveled over $[0,4]$.
  16. 16 Using the same velocity data ($v(0)=3,\ v(1)=5,\ v(2)=4,\ v(3)=7,\ v(4)=6$), use Simpson's Rule to estimate the distance traveled over $[0,4]$.
  17. 17 If $f$ is concave up on $[a,b]$, does the Trapezoidal Rule overestimate or underestimate $\int_a^b f(x)\,dx$? Explain in one sentence.
  18. 18 State the error bound formula for the Trapezoidal Rule (define every symbol used).
  19. 19 Why is Simpson's Rule generally far more accurate than the Trapezoidal Rule for the same $n$?
  20. 20 Recall $\displaystyle\int_0^1 \sqrt{1+4x^2}\,dx$ gives the arc length of $y=x^2$ on $[0,1]$ (Section 6.3). Use Simpson's Rule with $n=4$ to approximate it.
