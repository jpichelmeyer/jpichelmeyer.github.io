Lesson

A rational function $\frac{P(x)}{Q(x)}$ is often easier to integrate after being decomposed into a sum of simpler fractions — each one directly integrable by earlier techniques.

Setup

If $\deg P \ge \deg Q$, do polynomial long division first, so the remaining fraction has $\deg(\text{numerator}) < \deg(\text{denominator})$. Then factor $Q(x)$ completely; every distinct linear factor $(ax+b)$ contributes a term $\dfrac{A}{ax+b}$ to the decomposition, with $A$ an unknown constant to solve for. (Repeated factors and irreducible quadratic factors need extra terms, covered in a fuller treatment than this lesson — the distinct-linear-factors case below covers the core idea.)

Example

Find $\displaystyle\int \frac{3x+5}{x^2-x-2}\,dx$.

Factor the denominator: $x^2-x-2=(x-2)(x+1)$. Write

$$\frac{3x+5}{(x-2)(x+1)} = \frac{A}{x-2}+\frac{B}{x+1}$$

Multiply both sides by $(x-2)(x+1)$: $3x+5 = A(x+1)+B(x-2)$.

Choose convenient values of $x$ to isolate each constant. At $x=2$: $11 = 3A \Rightarrow A=\frac{11}{3}$. At $x=-1$: $2 = -3B \Rightarrow B=-\frac23$.

$$\int\frac{3x+5}{x^2-x-2}\,dx = \frac{11}{3}\int\frac{dx}{x-2} - \frac23\int\frac{dx}{x+1} = \frac{11}{3}\ln|x-2| - \frac23\ln|x+1| + C$$

  16. 16 Write the correct partial fraction decomposition form for $\dfrac{x+4}{(x-3)^2(x+1)}$.
  17. 17 Write the correct partial fraction decomposition form for $\dfrac{3x^2-x+1}{x(x^2+4)}$.

  19. 19 A chemical reaction's rate leads to $\dfrac{dx}{dt}=k(a-x)(b-x)$ with $a\ne b$. After separating variables, the left side becomes $\displaystyle\int \frac{dx}{(a-x)(b-x)}$. Decompose this integrand into partial fractions (treat $a,b$ as constants).
  20. 20 Evaluate $\displaystyle\int \frac{x}{x^2-5x+6}\,dx$.
