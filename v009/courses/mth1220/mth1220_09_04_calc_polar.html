Lesson

A polar curve $r=f(\theta)$ can be viewed as the parametric curve $x=f(\theta)\cos\theta$, $y=f(\theta)\sin\theta$ with parameter $\theta$ — so both the slope formula and a new area formula follow from tools already built.

Slope

Apply the parametric slope formula to $x(\theta)=f(\theta)\cos\theta$, $y(\theta)=f(\theta)\sin\theta$:

$$\frac{dy}{dx} = \frac{dy/d\theta}{dx/d\theta} = \frac{f'(\theta)\sin\theta+f(\theta)\cos\theta}{f'(\theta)\cos\theta-f(\theta)\sin\theta}$$

Area enclosed by a polar curve

The region swept out by $r=f(\theta)$ between $\theta=\alpha$ and $\theta=\beta$ has area

$$A = \frac12\int_{\alpha}^{\beta} [f(\theta)]^2\,d\theta$$

This comes from summing thin circular-sector areas ($\frac12 r^2\,d\theta$ each, the sector-area formula) rather than thin rectangles — a genuinely different building block from every earlier area/volume formula in this course.

Example

Find the area enclosed by one loop of the rose $r=2\sin(2\theta)$ (for $0\le\theta\le\frac\pi2$, tracing one petal).

$$A = \frac12\int_0^{\pi/2} \big[2\sin(2\theta)\big]^2\,d\theta = \frac12\int_0^{\pi/2} 4\sin^2(2\theta)\,d\theta = 2\int_0^{\pi/2}\sin^2(2\theta)\,d\theta$$

Using the half-angle identity $\sin^2 u = \frac{1-\cos 2u}{2}$ with $u=2\theta$:

$$2\int_0^{\pi/2} \frac{1-\cos(4\theta)}{2}\,d\theta = \int_0^{\pi/2}\big(1-\cos 4\theta\big)\,d\theta = \left[\theta-\frac{\sin4\theta}{4}\right]_0^{\pi/2} = \frac{\pi}{2}$$
