Practice Examples

Work out your answers to the following questions on paper, then check your answers below.

  1. 1 Use the Ratio Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{2^n}{n!}$ converges.
  2. 2 Use the Ratio Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{n!}{3^n}$ converges.
  3. 3 Use the Ratio Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{n^n}{n!}$ converges.
  4. 4 Use the Ratio Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{n}{2^n}$ converges.
  5. 5 Use the Ratio Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{(2n)!}{(n!)^2}$ converges.
  6. 6 Use the Ratio Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{n^2}{2^n}$ converges.
  7. 7 Use the Root Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \left(\frac{n}{2n+1}\right)^n$ converges.
  8. 8 Use the Root Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \frac{3^n}{n^n}$ converges.
  9. 9 Use the Root Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \left(1+\frac1n\right)^{n^2}$ converges.
  10. 10 Use the Root Test to determine whether $\displaystyle\sum_{n=1}^{\infty} \left(\frac{2n+1}{3n+2}\right)^n$ converges.
  11. 11 Would the Ratio Test or the Root Test be the more natural first choice for $\displaystyle\sum \frac{n!}{n^n}$? Why?
  12. 12 Would the Ratio Test or the Root Test be the more natural first choice for $\displaystyle\sum \left(\frac{n+1}{3n-1}\right)^{2n}$? Why?
  13. 13 Would the Ratio Test or the Root Test be the more natural first choice for $\displaystyle\sum \frac{3^n\,n!}{n^n}$? Why?
  14. 14 For $\displaystyle\sum_{n=1}^{\infty} \frac{5^n}{n^{10}}$, which test is more efficient, and what does it conclude?
  15. 15 Apply the Ratio Test to $\displaystyle\sum_{n=1}^{\infty} \frac{1}{n^2}$. What do you get, and what must you conclude about the test itself?
  16. 16 Apply the Ratio Test to $\displaystyle\sum_{n=1}^{\infty} \frac{1}{n}$. What do you get, and how does this illustrate a limitation of the test?
  17. 17 State the Ratio Test in full, including all three cases based on the value of $L$.
  18. 18 State the Root Test in full, including all three cases based on the value of $L$.
  19. 19 For what values of $x$ does $\displaystyle\sum_{n=1}^{\infty} \frac{x^n}{n!}$ converge, according to the Ratio Test?
  20. 20 For what values of $x$ does $\displaystyle\sum_{n=1}^{\infty} n\,x^n$ converge, according to the Ratio Test?

  3. 3.$L=e>1$ — diverges.
  4. 4.$L=\dfrac12<1$ — converges.
  5. 5.$L=4>1$ — diverges.
  6. 6.$L=\dfrac12<1$ — converges.
  7. 7.$L=\dfrac12<1$ — converges.
  8. 8.$L=0<1$ — converges.
  9. 9.$L=e>1$ — diverges.
  10. 10.$L=\dfrac23<1$ — converges.
  11. 11.Ratio Test — the factorial simplifies nicely under a ratio ($\tfrac{(n+1)!}{n!}=n+1$), which is awkward to handle with an $n$th root.
  12. 12.Root Test — the entire term is already raised to the $n$th power (times $2$), so taking an $n$th root cancels the exponent directly.
  13. 13.Ratio Test — both the factorial and the exponential simplify cleanly in a ratio of consecutive terms.
  14. 14.The Ratio Test: $L=\displaystyle\lim_{n\to\infty}\left|\frac{5^{n+1}/(n+1)^{10}}{5^n/n^{10}}\right|=5>1$ — diverges.
  15. 15.$L=1$ — the Ratio Test is inconclusive. (The series actually converges, but you'd need the $p$-series test to see that.)
  16. 16.$L=1$ — inconclusive, exactly as with $\sum 1/n^2$ above, yet this series \emph{diverges}. The Ratio Test cannot distinguish these two cases when $L=1$; you always need a different test.
  17. 17.Let $L=\displaystyle\lim_{n\to\infty}\left|\dfrac{a_{n+1}}{a_n}\right|$. If $L<1$, $\sum a_n$ converges absolutely; if $L>1$ (or $L=\infty$), it diverges; if $L=1$, the test is inconclusive.
  18. 18.Let $L=\displaystyle\lim_{n\to\infty}\sqrt[n]{|a_n|}$. If $L<1$, $\sum a_n$ converges absolutely; if $L>1$ (or $L=\infty$), it diverges; if $L=1$, the test is inconclusive.
