This lab turns the first two lessons into a working device. You wire two LEDs and two buttons, debounce the buttons, and drive a three-state status panel without ever sleeping. The panel is small, but the structure (a table of states, a function for the outputs, and a loop that never blocks) is the pattern for the rest of the course.

What You Will Build

A small status panel for a robot: two buttons and two LEDs that show what the robot is doing. Button A arms and disarms it, button B simulates a sensor trip. When tripped while armed, the panel raises an alarm until it is reset. The panel is a tiny state machine, and it is the first piece of the larger systems you will build all term.

Wiring

Lab 1 connections as a list of loops. Each LED has its own resistor between the pin and the LED, and its other leg goes to ground. Each button connects its pin to ground when pressed, and uses the Pico’s internal pull-up (no external resistor). Build on the breadboard and keep wires short.

Build it in two steps and test each: first the LEDs (use led.on() in the REPL), then the buttons (print button.value() while pressing). Do not write the full program until both halves work.

The State Machine

The three states and the button events that move between them. Any combination not drawn (such as B while IDLE) does nothing. Writing the machine as a table, not as nested if statements, makes it easy to read and to test.
panel.py MicroPython
from machine import Pin from time import ticks_ms from button import Button # the debounced Button class from the Circuits lesson TABLE = { ('IDLE', 'A'): 'ARMED', ('ARMED', 'A'): 'IDLE', ('ARMED', 'B'): 'ALARM', ('ALARM', 'A'): 'IDLE', } def next_state(state, event): return TABLE.get((state, event), state) # unknown pairs: stay where you are def leds_for(state, now_ms): """Return (red, green) for this state at this moment. No sleeping, just arithmetic.""" if state == 'IDLE': return (0, (now_ms // 500) % 2) # green: 500 ms on, 500 ms off (1 Hz) if state == 'ARMED': return (0, 1) return ((now_ms // 125) % 2, 0) # ALARM: red toggles every 125 ms (4 Hz) red, green = Pin(8, Pin.OUT), Pin(9, Pin.OUT) a, b = Button(6), Button(7) state = 'IDLE' while True: ea, eb = a.pressed(), b.pressed() # call both every loop so no press is skipped event = 'A' if ea else ('B' if eb else None) if event: new = next_state(state, event) if new != state: print(ticks_ms(), state, '->', new) # a log line for each change state = new r, g = leds_for(state, ticks_ms()) red.value(r) green.value(g)

Save button.py (from the Circuits lesson) on the Pico next to this file so from button import Button works. The loop never sleeps: each pass reads the buttons, decides, and sets the LEDs, thousands of times a second. The blinking comes from arithmetic on the clock, not from sleep_ms.

Warm Up

Exercise 1: Trace It

A: ARMED. B: ALARM. A: IDLE. B: IDLE (ignored). A: ARMED. B: ALARM. The alarm triggers twice (the first and the last B). The fourth event is ignored because B only matters in ARMED.

Exercise 2: Read the Pattern

IDLE: green is (now // 500) % 2, which gives 0, 0, 1 at 0, 400 and 600 ms (0 // 500 = 0, 400 // 500 = 0, 600 // 500 = 1), and red is always 0. ALARM: red is (now // 125) % 2, which gives 0, 1, 0 (0 // 125 = 0, 400 // 125 = 3, 600 // 125 = 4), and green is always 0. So IDLE gives (0,0), (0,0), (0,1) and ALARM gives (0,0), (1,0), (0,0), as (red, green) pairs.

Intermediate

Exercise 3: Test the Machine Without Hardware
test_panel.py MicroPython
state = 'IDLE' alarms = 0 for ev in ['A', 'B', 'A', 'B', 'A', 'B']: new = next_state(state, ev) if new == 'ALARM' and state != 'ALARM': alarms += 1 state = new print(state, alarms) # ALARM 2

Because next_state is a pure function (no pins, no clock) it runs anywhere. Keeping the decision separate from the hardware is what makes it testable.

Advanced

Exercise 4: Long Press Resets

Track when the button went down. Once it has been held for the required time, report once and then stay quiet until it is released.

longpress.py MicroPython
class LongPress: def __init__(self, hold_ms=1000): self.hold_ms = hold_ms self.down_at = None self.fired = False def update(self, is_down, now_ms): if not is_down: self.down_at, self.fired = None, False return False if self.down_at is None: self.down_at = now_ms if not self.fired and now_ms - self.down_at >= self.hold_ms: self.fired = True return True # true exactly once per long press return False
test_longpress.py MicroPython
lp = LongPress() events = [] for t in range(0, 3000, 100): held = 200 <= t < 2500 # held from 200 ms to 2.5 s if lp.update(held, t): events.append(t) print(events) # [1200]: once, a second after pressing
