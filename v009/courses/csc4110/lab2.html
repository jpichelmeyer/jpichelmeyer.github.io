This lab puts the whole week together on a sensor you haven't used yet: a photoresistor (LDR), whose resistance changes with how much light hits it. You'll wire it into a voltage divider so the Pico can read it as a voltage, sample it, filter it, and use the result to drive the onboard LED, a complete small analog pipeline, sensor to decision.

Why a Voltage Divider

A photoresistor doesn't output a voltage on its own, it just changes its resistance (ohms), lower resistance in bright light, higher in the dark. To turn a changing resistance into a changing voltage the ADC can read, you pair it with a fixed resistor in a voltage divider: two resistors in series across 3.3V and GND, with the ADC reading the voltage at the point where they meet.

The ADC reads the voltage at the junction between the two resistors, which depends on the ratio between them. Since the fixed 10kΩ resistor never changes, any change in that ratio, and therefore in the reading, comes entirely from the LDR's resistance, i.e. from light level.

Procedure

  1. Build the voltage divider circuit exactly as diagrammed, with the junction point wired to GP26.
  2. In the shell, confirm ADC(Pin(26)).read_u16() changes noticeably when you cover the LDR with your hand versus shine a phone flashlight on it. If it doesn't move much, check the divider's orientation, swapping the LDR and the fixed resistor's positions inverts which direction brighter light moves the reading.
  3. Combine the filtered-read pattern from this week's noise lesson with the LDR, using a window size of 8.
  4. Write a main.py that samples the LDR at 20 Hz through the filter, and turns the onboard LED on whenever the filtered reading drops below a threshold you choose by testing (i.e., the LED comes on when it's dark).
  5. Test it: cover the sensor slowly with your hand and confirm the LED switches on at a consistent, repeatable point, not flickering right at the threshold.
main.py (starting point -- fill in THRESHOLD) MicroPython
from machine import ADC, Pin from time import sleep sensor = ADC(Pin(26)) led = Pin("LED", Pin.OUT) THRESHOLD = 0 # TODO: find a sensible value by testing WINDOW_SIZE = 8 window = [] def filtered_read(): raw = sensor.read_u16() window.append(raw) if len(window) > WINDOW_SIZE: window.pop(0) return sum(window) / len(window) while True: level = filtered_read() led.value(1 if level < THRESHOLD else 0) sleep(0.05) # 20 Hz
How the reading responds to light. The curve is smooth but not straight, which is one reason to choose thresholds by measuring rather than calculating.

If the LED Flickers Near the Threshold

Even filtered, a reading hovering right at your chosen threshold can flicker the LED on and off rapidly as it drifts a tiny amount above and below the line. One common fix, worth trying if you hit this, is hysteresis: use two thresholds instead of one, a lower one to turn on and a noticeably higher one to turn back off, so the reading has to cross a real gap in either direction before the LED's state changes again. You're not required to implement this for the lab, but it's worth understanding as the standard answer to this exact symptom.

One threshold lets noise toggle the output as the signal hovers near it (top bar). Two thresholds make the output wait for a decisive change (bottom bar).

Warm Up

Exercise 1: Divider Arithmetic

V = 3.3 × 10 / (10 + RLDR). Bright: 3.3 × 10 / 12 = 2.75 V, about 54,600. Dark: 3.3 × 10 / 60 = 0.55 V, about 10,900. More light, higher reading, as the lab found.

Exercise 2: Swap the Parts

The reading now goes down as light increases (the divider is inverted). In the code, flip the comparison: turn the LED on when level > THRESHOLD instead of level < THRESHOLD.

Intermediate

Exercise 3: Add Hysteresis
main.py (loop) MicroPython
LOW, HIGH = 20000, 26000 dark = False while True: level = filtered_read() if level < LOW: dark = True elif level > HIGH: dark = False led.value(1 if dark else 0) sleep(0.05)

Between 20000 and 26000 the state simply stays as it was, which is what stops the flicker. The variable dark is the memory.

Advanced

Exercise 4: Self-Calibrating Thresholds
main.py MicroPython
from time import ticks_ms, ticks_diff # measure the baseline for 2 s total, n = 0, 0 start = ticks_ms() while ticks_diff(ticks_ms(), start) < 2000: total += sensor.read_u16() n += 1 sleep(0.02) baseline = total / n LOW = baseline * 0.70 HIGH = baseline * 0.85 print("baseline", baseline, "thresholds", LOW, HIGH)

Use the same LOW/HIGH loop as before. The device now adapts to whatever light it wakes up in, instead of needing thresholds hard-coded for one room.
