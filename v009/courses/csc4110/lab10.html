This lab puts the team's shared memory to work. You run the world model service from this week's lesson, every robot announces its role and reports what it knows, and every robot reads the shared view back as percepts with ages: a Scout reports where it sees something, a Pointer turns to face it, a Signaler shows the team's state to a human. Then you attack the shared memory on purpose: late joiners, a dead world service, two writers on one fact, disagreeing and lying robots. You measure each, because the mission in Lab 12 and Lab Practical 3 rests on this layer.

Step 2. Every Robot Reports

Each robot already announces stat/role with its pose (Lab 7). Measure your pose with a ruler on the arena and correct it. Every role uses the same geometry, so put it in one shared file:

pose.py MicroPython
# pose.py -- positions on the arena, shared by every role (cm, degrees counter-clockwise from +x) from math import atan2, cos, sin, radians, degrees def fix_from(pose, pan_deg, range_cm): """A Scout alone: where is the thing it sees at this pan angle and range?""" d = radians(pose["heading"] + pan_deg) return pose["x"] + range_cm * cos(d), pose["y"] + range_cm * sin(d) def pan_to(pose, x, y): """A Pointer or Watcher: which pan angle faces (x, y)? None if it is behind the robot.""" d = degrees(atan2(y - pose["y"], x - pose["x"])) - pose["heading"] d = (d + 180) % 360 - 180 # wrap into -180 .. 180 return d if -90 <= d <= 90 else None
test_pose.py MicroPython

# show.py -- a Signaler's 16 x 2 view of the world model (LCD from Lab 3) def lines(view): """view: a WorldView. Returns two 16-character lines.""" roster, r_age, _ = view.get("roster") alive = roster is not None and r_age < 3.0 # the roster ages too: no heartbeat, no count up = str(sum(1 for r in roster.values() if r["online"])) if alive else "?" tgt, t_age, t_ok = view.get("target") idn, _, i_ok = view.get("ident") if tgt and t_ok: top = "T %3d,%3d %4.1fs" % (round(tgt["x"]), round(tgt["y"]), t_age) elif tgt: top = "T stale %5.0fs" % t_age else: top = "T none" bottom = "%s up %s" % (up, ("%s %.0f%%" % (idn["label"], 100 * idn["conf"])) if idn and i_ok else "no ident") return top[:16].ljust(16), bottom[:16].ljust(16)

Notice the third case. The roster has no freshness flag of its own, but it still ages on the robot: if no roster message has arrived for three seconds, the Signaler shows “?” rather than a count it can no longer vouch for. A display that keeps showing “4 up” after the world service has died is lying to a human, which is worse than showing nothing.

Step 5. Two Writers on One Fact

Point two Scouts at the same tube, each publishing its own one-head fix. Both feed world/target, and the world model keeps whichever arrived last, so the shared fact flips between two slightly different answers. This is the hazard of Part 2 of the lesson, sneaking back through a single writer that does no merging. Count it:

flips.py Python
# flips.py -- how often did world/target change its source? (logger database, laptop) import json, sqlite3, sys db = sqlite3.connect(sys.argv[1]) rows = db.execute("SELECT ts, payload FROM msgs WHERE topic = 'world/target' ORDER BY ts").fetchall() srcs = [(ts, tuple(json.loads(p)["src"])) for ts, p in rows] flips = sum(1 for a, b in zip(srcs, srcs[1:]) if a[1] != b[1]) span = (srcs[-1][0] - srcs[0][0]) / 60 if len(srcs) > 1 else 1 print("%d messages, %d changes of source, %.1f per minute" % (len(srcs), flips, flips / span))

On a simulated minute with two Scouts reporting once a second each, a few centimetres apart, it printed: 120 messages, 119 changes of source, 120.0 per minute. Every change of source is a moment where the Pointer's target jumps. Watch the Pointer's beam while this runs, then propose a fix in your report. There are two good ones: merge the two fixes in the world model (average them, weighted by quality), or cross the two bearings properly in a fuser and give the world model one writer of positions, which is what Lab 12 does.

Solutions

Give each exercise an honest try before opening its solution.

Warm Up

Exercise 1: A Scout's Fix

The world direction is 90 + 20 = 110°. x = 60 + 70 cos 110° = 60 − 23.9 = 36.1; y = 0 + 70 sin 110° = 65.8. Positive pan is counter-clockwise, so +20° turns the head toward smaller x when it faces +y, which is why x went down.

Intermediate

Exercise 2: Predict the Ghost

On arrival the belief is about 0.3 s old (the 40 ms of transit are not counted, which is the small error of sending ages). The Pointer adds the time since arrival, so the belief reaches 2 s about 1.7 s after the last message arrived, and the next 50 ms check notices it: the beam goes off between 1.70 and 1.75 s after the last message. If you measured close to 2.7 s instead, look for a robot that forgot to add the time since arrival and is relying on the next heartbeat that will never come.

Advanced

Exercise 3: Merge, Don't Flip
merge.py Python
class MergingWorld(WorldModel): MERGE_S = 1.0 def __init__(self): super().__init__() self.fixes = {} # user -> (x, y, q, t) def ingest(self, topic, d, now): kept = super().ingest(topic, d, now) if kept and topic.endswith("/tele/fix"): self.fixes[topic.split("/")[1]] = (d["x"], d["y"], d.get("q", 0.0), now) return kept def snapshot(self, now): out = super().snapshot(now) fresh = {u: f for u, f in self.fixes.items() if now - f[3] <= self.MERGE_S} wsum = sum(f[2] for f in fresh.values()) if fresh and wsum > 0: x = sum(f[0] * f[2] for f in fresh.values()) / wsum y = sum(f[1] * f[2] for f in fresh.values()) / wsum q = max(f[2] for f in fresh.values()) t = max(f[3] for f in fresh.values()) out["world/target"] = self._belief({"x": round(x, 1), "y": round(y, 1), "q": q}, sorted(fresh), t, "target", now) return out
test_merge.py Python
w = MergingWorld() w.ingest("lab/amy/tele/fix", {"x": 31.0, "y": 50.0, "q": 0.5}, 10.0) w.ingest("lab/bo/tele/fix", {"x": 44.0, "y": 47.0, "q": 0.5}, 10.4) print(w.snapshot(10.5)["world/target"]["value"], w.snapshot(10.5)["world/target"]["src"]) print(w.snapshot(11.2)["world/target"]["value"], w.snapshot(11.2)["world/target"]["src"]) # amy too old
output Output
{'x': 37.5, 'y': 48.5, 'q': 0.5} ['amy', 'bo'] {'x': 44.0, 'y': 47.0, 'q': 0.5} ['bo']

The flipping stops: both readers now see one position between the two. But averaging two biased one-head fixes is not the same as crossing two bearings: if both Scouts see the near side of the tube, the average is biased too, and the quality of 0.5 says so. When one Scout falls silent the answer moves smoothly to the other's, which is what a degraded mode should do.
