You've been using strings since the very first lesson, mostly as whole values passed to print(). A string is actually a sequence, an ordered run of individual characters, and once you start treating it that way, a lot of new operations open up.

Part 1. Indexing

Each character in a string has a position, starting at 0. Square brackets pull out the character at a given index.

strings.py Python
s = "python" print(s[0]) # p, the first character print(s[-1]) # n, negative indices count from the end print(len(s)) # 6, the number of characters

Negative indices are genuinely useful, not just a curiosity: s[-1] is always the last character no matter how long the string is, without needing len(s) - 1 to work it out.

Part 2. Slicing

A slice pulls out a whole range at once: s[start:stop], up to but not including stop. Leave either side off and Python fills in "the beginning" or "the end" for you.

strings.py Python
s = "python" print(s[0:3]) # pyt print(s[3:]) # hon, everything from index 3 onward print(s[:3]) # pyt, everything up to (not including) index 3

A slice can also take a step, s[start:stop:step], and a neat trick falls straight out of that: s[::-1] (the whole string, stepping backward) reverses it.

Part 3. Strings Are Immutable

Once a string exists, it can't be changed in place, no character can be swapped out inside it. Trying to assign into an index raises an error.

strings.py Python
s = "python" s[0] = "P" # TypeError: 'str' object does not support item assignment

Anything that looks like it's "modifying" a string is actually building an entirely new one and handing that back: s.upper() doesn't change s, it returns a new, different string with the change already made. If you want to keep the result, you have to assign it, usually right back to the same name: s = s.upper().

Part 4. Useful String Methods

A method is a function that belongs to a value, called with a dot: value.method(). A few you'll reach for constantly:

strings.py Python
name = " Ada " print(name.strip()) # "Ada", leading/trailing whitespace gone print("PYTHON".lower()) # "python" print("python".upper()) # "PYTHON" print("hello world".replace("world", "there")) # "hello there" print("one,two,three".split(",")) # ['one', 'two', 'three']

split() is worth a second look: it turns one string into a list of smaller strings, breaking wherever the given separator shows up. You'll use this constantly once you're reading real, messy text input.

Part 5. f-strings

Back in an earlier lesson, building a message out of a string and a number needed an explicit str() conversion: "Score: " + str(95). An f-string does the same job more directly: put an f right before the opening quote, and anything inside { } gets evaluated and dropped into the string automatically, no manual conversion needed.

strings.py Python
age = 30 print(f"I am {age} years old") name = "Ada" print(f"Hello, {name}! You are {age}.")

Anything can go inside the braces, not just a bare variable, f"{2 + 2}" works exactly the way you'd expect. This is the idiomatic way to build a string out of mixed pieces in modern Python; reach for it over + concatenation whenever more than one or two pieces are involved.
