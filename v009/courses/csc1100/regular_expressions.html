.replace() and .split() both need to know the exact text they're looking for ahead of time. A regular expression (regex) describes a pattern instead, "a digit," "one or more letters," "something that looks like a phone number," letting you search for a shape rather than an exact string.

Part 1. The re Module

Regular expressions live in Python's built-in re module. re.search(pattern, text) looks for the pattern anywhere in text and returns a match object if it finds one, or None if it doesn't.

regex.py Python
import re text = "My phone number is 555-1234." match = re.search(r"\d{3}-\d{4}", text) print(match.group())

That r right before the quotes matters: it marks a raw string, telling Python not to treat backslashes specially, which matters a lot here since regex patterns use backslashes constantly for their own purposes. .group() pulls the actual matched text back out of the match object.

Part 2. Common Pattern Elements

  • \d: any digit
  • \w: any letter, digit, or underscore
  • .: any character at all (except a newline)
  • +: one or more of whatever came right before it
  • *: zero or more of whatever came right before it
  • {3}: exactly 3 of whatever came right before it (and {3,5} for a range)

\d{3}-\d{4} from Part 1 reads directly off this list: exactly 3 digits, a literal hyphen, exactly 4 digits. \d+ means "one or more digits," useful when you don't know the exact length ahead of time.

Part 3. Finding Every Match

re.search() only ever finds the first match. re.findall() returns every match in the text as a list.

regex.py Python
import re nums = re.findall(r"\d+", "I have 3 cats and 12 fish") print(nums)

Part 4. Pattern-Based Replacement

.replace() swaps one exact string for another. re.sub(pattern, replacement, text) does the same job, but the thing it's replacing can be an entire pattern instead of one fixed string.

regex.py Python
import re result = re.sub(r"\d+", "#", "I have 3 cats and 12 fish") print(result)

A single call replaces both 3 and 12, two different numbers, two different lengths, because the pattern describes "any run of digits," not one specific number.

Try It Yourself

Use re.findall() with \w+ to pull every word out of a sentence, punctuation and all excluded.

Notice It's split into It and s, the apostrophe isn't a letter, digit, or underscore, so \w+ stops right there. Patterns match exactly what you tell them to, nothing more, which is worth remembering the first time a regex "almost" works.
