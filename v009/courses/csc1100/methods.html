__init__ is actually just a method, a function defined inside a class. Any function you define the same way becomes something every instance of that class can do.

Part 1. Defining a Method

methods.py Python
class Dog: def __init__(self, name): self.name = name def bark(self): print(self.name + " says woof!") d = Dog("Rex") d.bark()

d.bark() is the call, but notice bark is defined taking self and nothing else, yet it's called with no arguments at all. Python fills self in automatically, it's d itself, passed silently every time you call a method through an instance.

Part 2. Why self Has to Be There

self is how a method reaches the specific instance it was called on. Without it, bark would have no way to know whose name to print, self.name is exactly what ties the method back to this particular dog rather than dogs in general.

You'll never pass self yourself when calling a method, Python always supplies it, but you always write it as the first parameter when defining one.

Part 3. Class Variables vs. Instance Variables

An attribute set inside __init__ with self. belongs to one instance. A variable defined directly inside the class, outside any method, is shared by every instance at once.

methods.py Python
class Counter: total_created = 0 # class variable, shared by every instance def __init__(self): Counter.total_created += 1 c1 = Counter() c2 = Counter() c3 = Counter() print(Counter.total_created)

Each Counter() call adds one to the same shared number, not a separate one per instance, which is exactly why the count ends at 3 instead of resetting for each object.

Part 4. Customizing print() with __str__

By default, printing an instance shows something unreadable, like <__main__.Dog object at 0x...>. Defining __str__ tells Python exactly what to show instead.

methods.py Python
class Dog: def __init__(self, name): self.name = name def __str__(self): return "Dog named " + self.name d = Dog("Rex") print(d)

__str__ is one of several "dunder" (double-underscore) methods Python calls automatically in specific situations, this one specifically whenever something needs a readable string version of your object, print() included.

class ShoppingCart: def __init__(self): self.items = {} def add_item(self, name, price, quantity=1): if name in self.items: old_price, old_qty = self.items[name] self.items[name] = (old_price, old_qty + quantity) else: self.items[name] = (price, quantity) def remove_item(self, name): if name in self.items: del self.items[name] def total(self): t = 0 for price, qty in self.items.values(): t += price * qty return t def __str__(self): lines = "" for name, (price, qty) in self.items.items(): lines += f"{name} x{qty} @ ${price:.2f}\n" return lines + f"Total: ${self.total():.2f}" cart = ShoppingCart() cart.add_item("apple", 0.5, 2) cart.add_item("bread", 3.25) cart.add_item("apple", 0.5) cart.add_item("gum", 1.0) cart.remove_item("gum") cart.remove_item("caviar") print(cart)

Exercise 9: Fractions
methods.py Python
import math class Fraction: def __init__(self, numerator, denominator): g = math.gcd(numerator, denominator) self.numerator = numerator // g self.denominator = denominator // g def add(self, other): n = self.numerator * other.denominator + other.numerator * self.denominator d = self.denominator * other.denominator return Fraction(n, d) def multiply(self, other): return Fraction(self.numerator * other.numerator, self.denominator * other.denominator) def __str__(self): return f"{self.numerator}/{self.denominator}" half = Fraction(1, 2) quarter = Fraction(2, 8) print(quarter) print(half.add(quarter)) print(half.multiply(quarter)) print(half)
