Every built-in function you've used so far, print, len, range, was available without asking for it. A module is a file of reusable code that isn't loaded automatically, you bring it in on purpose with import when you actually need it.

Part 1. import

math is part of Python's standard library, always available, no separate installation needed. Once imported, its functions and values are reached through the module's name with a dot, the same syntax you've already used for string methods.

modules.py Python
import math print(math.sqrt(16)) # 4.0 print(math.pi) # 3.141592653589793

Part 2. from ... import ...

Importing specific names directly lets you drop the module prefix, at the cost of it being less obvious later which module a name actually came from.

modules.py Python
from math import sqrt, pi print(sqrt(16)) print(pi)

Part 3. Renaming with as

A module can be imported under a shorter alias, useful for a name you'll type constantly, or one that's long enough to be annoying.

modules.py Python
import math as m print(m.sqrt(25))

Part 4. Writing Your Own Module

Any .py file is a module, including ones you write yourself. If you had a file mymath.py sitting in the same folder as your program:

mymath.py Python
def double(x): return x * 2

another file in that same folder could use it exactly like math:

main.py Python
import mymath print(mymath.double(21)) # 42

The editor on this page only ever runs one file at a time, so this specific example isn't something you can try right here, but it works exactly this way in Thonny on your own computer: two .py files in the same folder, one importing the other by its filename, minus the .py.
