Every built-in function you've used so far, print, len, range, was available without asking for it. A module is a file of reusable code that isn't loaded automatically, you bring it in on purpose with import when you actually need it.

Part 1. import

math is part of Python's standard library, always available, no separate installation needed. Once imported, its functions and values are reached through the module's name with a dot, the same syntax you've already used for string methods.

modules.py Python
import math print(math.sqrt(16)) # 4.0 print(math.pi) # 3.141592653589793

Part 2. from ... import ...

Importing specific names directly lets you drop the module prefix, at the cost of it being less obvious later which module a name actually came from.

modules.py Python
from math import sqrt, pi print(sqrt(16)) print(pi)

Part 3. Renaming with as

A module can be imported under a shorter alias, useful for a name you'll type constantly, or one that's long enough to be annoying.

modules.py Python
import math as m print(m.sqrt(25))

Part 4. Writing Your Own Module

Any .py file is a module, including ones you write yourself. If you had a file mymath.py sitting in the same folder as your program:

mymath.py Python
def double(x): return x * 2

another file in that same folder could use it exactly like math:

main.py Python
import mymath print(mymath.double(21)) # 42

The editor on this page only ever runs one file at a time, so this specific example isn't something you can try right here, but it works exactly this way in Thonny on your own computer: two .py files in the same folder, one importing the other by its filename, minus the .py.

Warm Up

Exercise 1: Circle Area. Import math and use math.pi to compute the area of a circle with radius 3 (area = pi times r squared). Print it rounded to 2 decimal places.

Exercise 2: Hypotenuse. Using from math import sqrt, write a function hypotenuse(a, b) that returns the length of the long side of a right triangle: the square root of a² + b².

Exercise 3: Exploring with an Alias. Import math under the alias m. Use it to print m.floor(7.8), m.ceil(7.2), and m.factorial(5). Predict each result first. Then use print(dir(m)) to list everything the module contains, and pick one function you haven't seen to try out.

Intermediate

Exercise 4: Dice Roller. The random module's random.randint(a, b) returns a random integer from a to b, inclusive. Write a function roll_dice(n) that rolls a six-sided die n times and returns the list of results, then print the rolls and their total. Run it a few times: the output should change every run, which is exactly why this editor has no expected output.

Exercise 5: The statistics Module. Python's standard library has a statistics module. Import it and print the mean, median, and mode of the ages list, using statistics.mean, statistics.median, and statistics.mode. Then check the median by hand: sort the list and find the middle value.

Exercise 6: Three Import Styles. The program below uses import math. Rewrite it twice more below it, once using from math import ... and once using import math as m, so that it prints the same two values three times. Which version would you prefer in a long program that also has its own variable called pi, and why?

Advanced

Exercise 7: Your Own Module (in Thonny). This one needs two files, so do it in Thonny rather than this page's editor. Create temperature.py containing two functions, c_to_f(c) and f_to_c(f). In the same folder, create main.py that does import temperature and prints temperature.c_to_f(100) and temperature.f_to_c(32). Run main.py. Then change it to use from temperature import c_to_f and confirm it still works.

Exercise 8: Who Am I? __name__. Every module has a built-in variable __name__. When a file is run directly, its __name__ is "__main__"; when it's imported, __name__ is the module's own name. Print __name__ for this program and math.__name__ for the imported module.

Then, in Thonny: add a test line like print(c_to_f(100)) to the bottom of your temperature.py from Exercise 7 and run main.py. The test runs on import, which you don't want. Fix it by putting the test inside if __name__ == "__main__":.

Exercise 9: Estimating pi with Randomness. Throw n random darts at a 1 by 1 square: each dart is a point (x, y) where x = random.random() and y = random.random() (each between 0 and 1). The fraction of darts that land inside the quarter circle, where x² + y² ≤ 1, is about pi / 4. Write estimate_pi(n) using this idea, then print your estimate for n = 1000 and n = 100000 next to math.pi. How does the accuracy change as n grows?

Exercise 7: Your Own Module (in Thonny)

temperature.py:

modules.py Python
def c_to_f(c): return c * 9 / 5 + 32

def f_to_c(f): return (f - 32) * 5 / 9

modules.py Python

With from temperature import c_to_f, the call becomes just c_to_f(100).

Exercise 8: Who Am I? __name__
modules.py Python
import math print(__name__) print(math.__name__)

For the Thonny part, the bottom of temperature.py becomes:

modules.py Python
if __name__ == "__main__": print(c_to_f(100))

That test now runs when temperature.py is run directly, but not when main.py imports it.

Exercise 9: Estimating pi with Randomness
modules.py Python
import random import math def estimate_pi(n): inside = 0 for i in range(n): x = random.random() y = random.random() if x ** 2 + y ** 2 <= 1: inside += 1 return 4 * inside / n print(estimate_pi(1000)) print(estimate_pi(100000)) print(math.pi)
