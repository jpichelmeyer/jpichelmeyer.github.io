A lot of classes you'd want to write are variations on something more general. A Puppy is still an Animal, with everything an Animal has, plus a little extra. Inheritance lets a class build on another one instead of duplicating it from scratch.

Part 1. A Base Class and a Child Class

Put the class you're inheriting from in parentheses after the new class's name. The child automatically gets everything the parent has.

inheritance.py Python
class Animal: def __init__(self, name): self.name = name def speak(self): return "..." class Dog(Animal): def speak(self): return self.name + " says Woof!" a = Animal("Generic") print(a.speak()) d = Dog("Rex") print(d.speak())

Dog never redefines __init__, it doesn't need to, it inherits Animal's version automatically, which is exactly why Dog("Rex") already knows how to set self.name.

Part 2. Overriding a Method

Dog above redefines speak, that's an override: the child's version replaces the parent's for instances of the child, while the parent's own instances are completely unaffected.

inheritance.py Python
a = Animal("Generic") print(a.speak()) # ..., Animal's own version, untouched d = Dog("Rex") print(d.speak()) # Rex says Woof!, Dog's overridden version

Part 3. super()

Sometimes a child class wants to extend the parent's behavior rather than fully replace it, run the parent's version first, then add something on top. super() gives you a way to call the parent's version explicitly from inside the child.

inheritance.py Python
class Puppy(Dog): def __init__(self, name): super().__init__(name) # let Dog (and Animal) set up self.name self.is_puppy = True def speak(self): base = super().speak() # get Dog's version of speak() first return base + " (but it's just a squeaky little bark)" p = Puppy("Biscuit") print(p.speak()) print(p.is_puppy)

Puppy inherits from Dog, which inherits from Animal, a chain, not just a single link. super().__init__(name) reaches up to Dog's constructor (which itself falls through to Animal's, since Dog never overrode it) rather than Puppy needing to repeat self.name = name itself.

inheritance.py Python
class Shape: def describe(self): return f"{type(self).__name__} with area {self.area()}" class Rectangle(Shape): def __init__(self, width, height): self.width = width self.height = height def area(self): return self.width * self.height class Square(Rectangle): def __init__(self, side): super().__init__(side, side) print(Rectangle(3, 5).describe()) print(Square(4).describe()) print(Square(4).width, Square(4).height)

class Person: def __init__(self, name, age): self.name = name self.age = age def __str__(self): return f"{self.name} ({self.age})" class Student(Person): def __init__(self, name, age, major): super().__init__(name, age) self.major = major def __str__(self): return super().__str__() + f", studying {self.major}" print(Person("Alan", 41)) print(Student("Ada", 19, "Computer Science"))
Exercise 9: Refactor Out the Duplication
inheritance.py Python
class Animal: def __init__(self, name, age): self.name = name self.age = age def birthday(self): self.age += 1 return f"{self.name} is now {self.age}" class Cat(Animal): def sound(self): return "Meow" class Dog(Animal): def sound(self): return "Woof" print(Cat("Tom", 3).birthday()) print(Dog("Rex", 5).birthday()) print(Cat("Tom", 3).sound(), Dog("Rex", 5).sound())

Checkpoint

Before moving on, make sure you can:

  1. Create a child class that inherits from a parent class, and explain what it gets automatically.
  2. Override a method in a child class, and explain why the parent's own instances are unaffected.
  3. Explain what super() does, and why you'd reach for it instead of just rewriting the parent's logic.
  4. Follow an inheritance chain more than one class deep.
