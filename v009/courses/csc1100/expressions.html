An expression is anything that evaluates down to a single value: a plain number, a variable, or several of those combined with operators. 3 + 4 is an expression (it evaluates to 7), and so is just 3 on its own. An assignment like x = 3 + 4 is not itself an expression, it's a statement that takes the expression on the right, evaluates it, and stores the result in x.

Part 1. Arithmetic Operators

The usual suspects, plus two that surprise people coming from other languages:

expressions.py Python
print(3 + 4) # addition: 7 print(3 - 4) # subtraction: -1 print(3 * 4) # multiplication: 12 print(7 / 2) # division: 3.5, always a float, even if it divides evenly print(7 // 2) # floor division: 3, rounds down to a whole number print(7 % 2) # modulo: 1, the remainder left over print(2 ** 10) # exponent: 1024

/ and // are genuinely different operators, not two spellings of the same thing: / always gives you a float back, and // throws away anything after the decimal point. Mixing them up is one of the most common early bugs.

Part 2. Order of Operations

Python follows the same order of operations you already know from math class: exponents first, then multiplication and division, then addition and subtraction, left to right within each level. Parentheses override all of it.

expressions.py Python
print(2 + 3 * 4) # 14, the multiplication happens first print((2 + 3) * 4) # 20, parentheses force the addition first

When in doubt, add parentheses. They cost nothing, and they make the order obvious to whoever reads the code next (including you, in a week).

Part 3. Mixing Types

An int and a float mix together fine, Python quietly promotes the result to a float. Strings are a different story: + between two strings joins them, but + between a string and a number is an error, Python won't guess what you meant.

expressions.py Python
print(3 + 4.0) # 7.0, an int and a float mix into a float print("3" + "4") # "34", two strings joined together print("Score: " + 95) # TypeError: can't add a str and an int directly

The fix is to convert explicitly with str(), int(), or float(), whichever direction you need:

expressions.py Python
print("Score: " + str(95)) # "Score: 95", now both sides are strings

Once it prints 68.0, try changing c_temp to 100.0 and -40.0 to check your formula against temperatures you already know.

Exercise 3: Predict the Output. Write down what you think each line prints, then run it. Two of these are designed to surprise you: 2 ** 3 ** 2 (exponents group from the right) and -7 // 2 (floor division always rounds down, toward negative infinity, not toward zero).

Intermediate

Exercise 4: Bill & Tip Calculator. A meal costs bill = 50.0. Tax is 7% and the tip is 18%, both calculated on the original bill. Compute the total and print it in the format Total: $62.5. Use round(total, 2) to round to two decimal places, and str() to join the number onto the text. Then change the tip rate to 20% and see how the total changes.

Exercise 5: Parentheses Repair. This is supposed to compute the average of three test scores, which should be 90.0. It prints something much larger. Explain what order Python is actually evaluating it in, then fix it by adding parentheses.

Exercise 6: Digit Extraction. Given n = 4729, use only // and % (no strings) to pull out each digit. Print the ones digit, tens digit, hundreds digit, and thousands digit on separate lines, in that order, then print the sum of all four digits. Hint: n % 10 is the ones digit, and n // 10 chops the ones digit off.

Advanced

Exercise 7: Change Maker. A vending machine owes you cents = 289. Using // and %, work out the fewest coins it can give you: as many quarters (25) as possible, then dimes (10), then nickels (5), then pennies (1). Print each count using the labels in the starter code. After it works for 289, try a few other amounts and check them by hand.

Exercise 8: Compound Interest. An account starts with principal = 1000.0 and earns 5% interest per year, compounded yearly. After years years it holds principal * (1 + rate) ** years. Compute the amount after 10 years and print it rounded to 2 decimal places. Then answer: roughly how many years does it take to double? Try changing years until you find out.

Exercise 9: Type Mixing Puzzle. For every line, predict both the value and the type of the result before running. The last line is commented out because it raises an error: predict which error, then uncomment it to check, then fix it two different ways (one that produces 9 and one that produces "72").
