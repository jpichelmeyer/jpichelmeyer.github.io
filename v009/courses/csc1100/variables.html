A variable is a name that points at a value. Once you have a name for something, you can use the name instead of retyping the value everywhere, and you can change what it points at as your program runs.

Part 1. Making a Variable

Assignment is the basic move: a name, an equals sign, a value.

variables.py Python
x = 5 print(x)

Python doesn't make you declare what kind of thing x is ahead of time, the way some languages do. You just assign it a value, and Python figures the rest out. Try it yourself:

Part 2. Naming Rules

A variable name can use letters, digits, and underscores, but it can't start with a digit, and it's case sensitive (score and Score are two different names). A handful of words are reserved by Python itself (if, for, class, and so on) and can't be used as variable names at all.

variables.py Python
student_name = "Ada" # valid _count = 0 # valid, starts with underscore 2fast = True # invalid: starts with a digit class = "CSC1100" # invalid: class is reserved

The convention in Python (not a hard rule, but one you should follow) is snake_case: lowercase words separated by underscores, like student_name rather than StudentName or studentName. Following the convention matters more than it might seem, code that looks like everyone else's Python is much easier for someone else (including future you) to read.

Part 3. A Few Basic Types

Every value in Python has a type: what kind of thing it is. The built-in type() function tells you.

variables.py Python
print(type(5)) # int, a whole number print(type(5.0)) # float, a number with a decimal point print(type("hi")) # str, text print(type(True)) # bool, True or False

Part 4. Reassignment

A variable isn't locked to its first value, or even its first type. Assigning it again just points the name at something new.

variables.py Python
x = 5 print(x) x = "now text" print(x)

Both lines print without error. x was an int, then it became a str, and Python didn't complain, the name was never actually tied to a type, only to whatever value it currently holds.
