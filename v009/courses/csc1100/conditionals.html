Every program so far has run top to bottom, every line, every time. Conditionals are what let a program actually make a decision: run this block if something is true, skip it (or run something else) if it isn't.

Part 1. Booleans and Comparisons

Comparing two values gives you back a bool, either True or False. Those are the two values a condition is ultimately built out of.

conditionals.py Python
print(5 > 3) # True print(5 == 5) # True, == checks equality (one variable is assignment, two is comparison) print("cat" == "dog") # False

== and = look similar and do very different things: = assigns, == compares. Mixing them up is one of the most common early bugs, and Python won't always catch it for you.

Part 2. if Statements

An if statement runs its block only when the condition is True. Python marks that block with indentation, not braces or an end keyword: whatever's indented under the if belongs to it.

conditionals.py Python
age = 20 if age >= 18: print("adult")

Change age below to something under 18 and run it again, nothing prints, since the condition is now false and the whole indented block just gets skipped.

Part 3. if / else

else catches everything the if didn't. Exactly one of the two blocks runs, never both, never neither.

conditionals.py Python
age = 15 if age >= 18: print("adult") else: print("minor")

Part 4. elif Chains

Real decisions are rarely just two-way. elif (short for "else if") checks another condition only if every one above it was false, and Python stops at the first one that's true, later branches never even get checked.

conditionals.py Python
def grade(score): if score >= 90: return "A" elif score >= 80: return "B" elif score >= 70: return "C" else: return "F" print(grade(85)) print(grade(62))

Notice the order matters: a score of 95 matches score >= 90 first and returns "A" immediately, it never gets the chance to also match score >= 80. If the branches were written in the opposite order, every score of 80 or above would incorrectly get "B".

Part 5. Combining Conditions

and, or, and not combine or invert boolean values. and needs both sides true, or needs at least one, not flips whatever follows it.

conditionals.py Python
age = 25 has_id = True print(age >= 21 and has_id) # True: both sides are true print(age < 18 or has_id) # True: at least one side is true print(not has_id) # False: flips True to False

Python also lets you chain comparisons the way you'd write them in math class, 5 < n < 20 really does mean "n is between 5 and 20," not something you need and to spell out.

  • Anything heavier than 5 kg costs 20.

Be careful with the boundaries: exactly 1 kg and exactly 5 kg should both cost 10.
