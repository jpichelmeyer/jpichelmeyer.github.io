A dictionary can bundle related values together, {"name": "Rex", "breed": "Labrador"}, but it has no built-in notion of "this is specifically a dog," and no way to attach behavior to it. A class is how you define your own type: a blueprint that bundles data and the functions that work on that data into one thing.

Part 1. Defining a Class

class defines a new type. __init__ is a special method Python calls automatically every time a new instance gets created, its job is to set up that instance's starting values.

classes.py Python
class Dog: def __init__(self, name, breed): self.name = name self.breed = breed d = Dog("Rex", "Labrador") print(d.name) print(d.breed)

self refers to the specific instance being created or worked on, it's what lets self.name = name attach name to this particular dog, rather than to dogs in general. You'll see self as the first parameter of essentially every method you write; more on exactly why in the next lesson.

Part 2. Each Instance Is Independent

Creating a second Dog doesn't touch the first one at all. Every instance gets its own separate copy of the attributes __init__ set up.

classes.py Python
d = Dog("Rex", "Labrador") d2 = Dog("Fido", "Poodle") print(d.name, d2.name) # Rex Fido, completely independent

This is really the whole point of a class: Dog is a blueprint, and each call to Dog(...) builds one more independent object from it, the same shape every time, different contents.

Exercise 6: Functions That Take Objects
classes.py Python
class Pet: def __init__(self, name, species, age): self.name = name self.species = species self.age = age def describe(pet): return f"{pet.name} the {pet.species}, age {pet.age}" def is_senior(pet): return pet.age >= 7 milo = Pet("Milo", "cat", 3) rex = Pet("Rex", "dog", 9) print(describe(milo)) print(is_senior(milo)) print(describe(rex)) print(is_senior(rex))

Exercise 8: From Dictionaries to Objects
classes.py Python
catalog = [ {"code": "CSC1100", "title": "Intro to Computing", "credits": 4}, {"code": "MTH1010", "title": "Calculus I", "credits": 5}, {"code": "ENG1000", "title": "Writing", "credits": 3}, ] class Course: def __init__(self, code, title, credits): self.code = code self.title = title self.credits = credits courses = [] for entry in catalog: courses.append(Course(entry["code"], entry["title"], entry["credits"])) for c in courses: if c.credits >= 4: print(c.code, c.title)
Exercise 9: Validating in __init__
classes.py Python
class Temperature: def __init__(self, kelvin): if kelvin < 0: raise ValueError("below absolute zero") self.kelvin = kelvin self.celsius = round(kelvin - 273.15, 2) for k in [300, 0, -5]: try: t = Temperature(k) print(t.kelvin, t.celsius) except ValueError as e: print("error:", e)
