Computers are good at doing the same thing over and over without getting bored. Loops are how you tell a program to repeat a block of code, either a fixed number of times, or for as long as some condition stays true.

A quick, honest warning before you start typing: it's easy to accidentally write a loop that never ends. If the editor below ever seems stuck (nothing happening, no output), reload this page; the code you were running will stop.

Part 1. while Loops

A while loop checks its condition, and if it's true, runs the block, then checks again, and again, for as long as the condition stays true.

loops.py Python
i = 1 while i <= 5: print(i) i += 1

That i += 1 matters more than it looks: it's what eventually makes the condition false. Delete it (or forget to indent it into the loop) and i never changes, the condition is true forever, and the loop never stops. That's the single most common way an intro program accidentally hangs.

Part 2. for Loops and range()

When you know how many times to repeat something, a for loop paired with range() is usually the cleaner tool. range(5) produces the numbers 0 through 4, five values, starting at 0.

loops.py Python
for i in range(5): print(i)

range() can also take a start, a stop, and a step: range(2, 10, 2) starts at 2, stops before 10, and counts up by 2 each time.

Part 3. Looping Over a String

A for loop isn't limited to numbers, it can walk through anything with a sequence of items to visit, including a string, one character at a time.

loops.py Python
for ch in "cat": print(ch)

Part 4. The Accumulator Pattern

One of the most useful loop shapes: start a variable at some starting value before the loop, then update it a little on every pass. Adding up a list of numbers is the classic example.

loops.py Python
total = 0 for i in range(1, 6): total += i print(total)

total starts at 0, outside the loop, so it isn't reset back to zero on every pass, then total += i adds the current number to whatever's already been accumulated. This pattern (start outside, update inside) comes up constantly: totals, counts, running maximums, building up a result piece by piece.

Part 5. break and continue

break exits a loop immediately, before its condition would naturally end it. continue skips just the rest of the current pass and moves on to the next one.

loops.py Python
for i in range(10): if i == 5: break print(i)
loops.py Python
for i in range(5): if i % 2 == 0: continue print(i)

The first loop stops dead the moment i hits 5, it never even considers 5 through 9. The second one skips printing on every even number but keeps looping, it just moves straight to the next pass instead of stopping altogether.

As soon as you find one that divides evenly, record it and break out of the loop, there's no point checking further. After the loop, print 97 is prime or, for a number like 91, 91 is not prime (divisible by 7). Hint: start a variable like divisor = 0 before the loop and use it as a flag.
