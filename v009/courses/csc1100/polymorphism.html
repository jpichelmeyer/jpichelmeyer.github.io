Last lesson's Dog overrode speak() with its own version. Nothing stops a second, unrelated child class from overriding it a completely different way, same method name, same call, genuinely different behavior depending on which actual type you're holding. That's polymorphism: one interface, many shapes underneath it.

Part 1. Two Overrides of the Same Method

polymorphism.py Python
class Animal: def __init__(self, name): self.name = name def speak(self): return "..." class Dog(Animal): def speak(self): return self.name + " says Woof!" class Cat(Animal): def speak(self): return self.name + " says Meow!"

Dog and Cat aren't related to each other at all, they only share Animal as a common parent. Each overrides speak() independently, with no knowledge of what the other one does.

Part 2. Calling It Without Checking the Type

Here's the actual payoff: a loop can call .speak() on a whole list of different animal types, never once checking which one it's currently holding, and each object still does the right thing for its own type.

polymorphism.py Python
animals = [Dog("Rex"), Cat("Whiskers"), Dog("Fido")] for a in animals: print(a.speak())

The loop body is exactly three characters long past the variable name, a.speak(), and it never mentions Dog or Cat at all. Each object already knows how to answer for itself.

Part 3. Without Polymorphism

Worth seeing the alternative once, just to appreciate what got avoided. Without overriding speak() per class, the same loop would need to check the type of every single object itself before deciding what to do with it.

(illustrative, not recommended) Python
for a in animals: if isinstance(a, Dog): print(a.name + " says Woof!") elif isinstance(a, Cat): print(a.name + " says Meow!") # and one more elif for every new animal type you ever add, forever

Every new animal type would mean going back and adding another branch to every single place in the code that does this kind of check, instead of just writing one new class with its own speak() and being done. That growing pile of type checks scattered everywhere is exactly what polymorphism exists to avoid.
