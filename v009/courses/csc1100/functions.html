Every program so far has been one long, flat sequence of statements. A function lets you give a name to a piece of logic, write it once, and reuse it anywhere, as many times as you want, with different inputs each time.

Part 1. Defining and Calling

def defines a function. Nothing inside it runs until the function is actually called by name, elsewhere, later.

functions.py Python
def greet(): print("hello") greet()

Defining greet() doesn't print anything by itself, the def block just teaches Python what greet means. Only the call on the last line, greet(), actually runs the body.

Part 2. Parameters

A parameter is a placeholder name a function receives its input through. Whatever you pass in when calling it fills that placeholder for that one call.

functions.py Python
def add(a, b): return a + b print(add(3, 4))

return is different from print, and mixing them up is a very common early confusion. print just displays something on screen and hands nothing back to whatever called the function; return actually hands a value back, which is what lets print(add(3, 4)) work at all, add(3, 4) has to produce a real value for print to then display.

Part 3. Default Parameter Values

A parameter can have a default value, used automatically whenever the caller doesn't provide one.

functions.py Python
def greet2(name="friend"): print("hello, " + name) greet2() greet2("Ada")

The first call has nothing to fill name with, so it falls back to "friend". The second call supplies "Ada" explicitly, which overrides the default for that one call only.

Part 4. Recursion

A function is allowed to call itself. That's recursion, and it needs two things to actually work rather than loop forever: a base case (a condition simple enough to answer directly, no further calls needed) and a recursive case (a call to itself on a smaller version of the same problem, getting closer to the base case every time).

functions.py Python
def factorial(n): if n <= 1: return 1 # base case return n * factorial(n - 1) # recursive case print(factorial(5))

Trace it by hand: factorial(5) needs 5 * factorial(4), which needs 4 * factorial(3), and so on down to factorial(1), which finally just returns 1 without calling itself again. Then every pending multiplication resolves on the way back out: 1, 2*1, 3*2, 4*6, 5*24, landing on 120.

Forget the base case, or write one that's never actually reached, and a recursive function calls itself forever, the same underlying problem as a while loop whose condition never goes false, just spelled differently.

Try It Yourself

Write a recursive function countdown(n): if n is 0, print "liftoff" and stop, otherwise print n and call countdown(n - 1). Call it with countdown(3).

Checkpoint

Before moving on, make sure you can:

  1. Explain the difference between defining a function and calling it.
  2. Explain the difference between return and print, and why print(add(3, 4)) needs add to use return.
  3. Give a parameter a default value, and explain when that default actually gets used.
  4. Identify the base case and the recursive case in a recursive function, and explain what happens if the base case is missing.
