A quick tour: create a project, then get to know the editor.

Part 1. Creating a New Project

  1. Open Godot. You land on the Project Manager, which lists any existing projects.
  2. Click the + Create button in the top-left area.
  3. In the dialog that appears:
    • Give your project a name (e.g. MyFirstProject).
    • Choose a folder where it will be saved.
    • Choose Compatibility for the renderer.
  4. Click Create & Edit. Godot sets up the project folder and opens the main editor.

Part 2. Tour of the Editor

Once the editor opens, you'll see several panels ("docks") arranged around the screen. Here's what each one does.

2.1 The Full Editor Layout

2.2 Top Toolbar

Runs across the very top. Includes the 2D / 3D / Script / AssetLib tabs (top-center) that switch your main workspace, and the Play buttons (top-right) to run your project or the current scene.

2.3 Scene Dock

Top-left panel. Shows the node tree for the scene you currently have open: every object in your scene lives here as a node, nested to show parent/child relationships.

2.4 Viewport

The large central area. This is your canvas, where you visually place and arrange nodes for 2D or 3D scenes.

2.5 Inspector

Right-hand panel. Shows all the editable properties of whichever node is currently selected in the Scene dock: position, size, color, script variables, and so on.

2.6 FileSystem Dock

Bottom-left panel. A file browser for everything inside your project folder (scenes, scripts, images, sounds, etc).

2.7 Bottom Panel

Runs along the very bottom. Tabs here include Output (print statements and logs), Debugger (errors, breakpoints, performance), and others like Animation or Audio depending on context.
