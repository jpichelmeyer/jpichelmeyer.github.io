Flocking is what happens when you give a group of agents nothing but local, short-sighted rules about their nearest neighbors (no leader, no shared plan) and let the group-level motion emerge on its own. Every rule so far has reacted to one fixed target. A flock reacts to whichever neighbors happen to be nearby right now, a changing, local, several-at-once situation.

Part 1. The Idea

Craig Reynolds' original 1986 "boids" model comes down to three rules, each agent applying them only to whatever neighbors are nearby:

  • Separation: steer away from neighbors that are too close, so the flock doesn't collapse into a pile.
  • Alignment: steer to match the average heading of nearby neighbors, so the flock tends to move together.
  • Cohesion: steer toward the average position of nearby neighbors, so the flock stays a flock instead of drifting apart.

None of these rules mentions "the flock" as a thing; each boid only ever looks at whoever is close to it. The flocking shape is a side effect, not something anyone's steering toward directly.

Part 2. Sensing Neighbors

An agent needs to know who's nearby without a distance check against every other agent in the scene every frame. The tool for that is an Area2D: instead of asking "who's close" continuously, let Godot's physics engine tell you the moment someone enters or leaves.

Add an Area2D named DetectionArea as a child of Agent, with a CollisionShape2D child using a CircleShape2D (its radius is the neighbor-sensing range, try something like 100). Set both Collision Layer and Collision Mask to a dedicated layer, layer 2 works well, rather than leaving them on the default layer 1. That keeps flock-sensing isolated from anything else physics-related an agent might pick up later (an obstacle's collision shape, for instance); this Area2D should only ever notice other agents.

agent.gd GDScript
var _neighbors: Array[Agent2D] = [] func _ready() -> void: if color != null: modulate = color add_to_group("agents") if has_node("DetectionArea"): $DetectionArea.area_entered.connect(_on_detection_area_entered) $DetectionArea.area_exited.connect(_on_detection_area_exited) func _on_detection_area_entered(area: Area2D) -> void: var other = area.get_parent() if other is Agent2D and other != self and other not in _neighbors: _neighbors.append(other) func _on_detection_area_exited(area: Area2D) -> void: var other = area.get_parent() if other in _neighbors: _neighbors.erase(other)

Two Area2Ds only notice each other if both sides allow it: area_entered fires when another Area2D (another agent's own DetectionArea) overlaps this one. area.get_parent() gets from "which Area2D touched me" back to "which agent," and is Agent2D is the exact same type check the pathfinding scripts use elsewhere in this course, made possible because agent.gd declares class_name Agent2D. _neighbors stays current automatically from here: appended to on entry, erased on exit, no per-frame distance scanning required.

Part 3. Separation, Alignment, Cohesion

agent.gd GDScript
const FLOCK_SEPARATION_RADIUS: float = 40.0 func _steer_flock(delta_passed: float) -> void: # Nothing nearby: just wander until a neighbor shows up if _neighbors.is_empty(): _rotation_wander(delta_passed) _move_forward(delta_passed, RATE_MOVE) return var separation: Vector2 = Vector2.ZERO var heading_sum: Vector2 = Vector2.ZERO var position_sum: Vector2 = Vector2.ZERO var count: int = 0 for neighbor in _neighbors: if not is_instance_valid(neighbor): continue var offset: Vector2 = global_position - neighbor.global_position var dist: float = offset.length() # Separation: push away harder the closer a neighbor is, only within a tight radius if dist > 0.0 and dist < FLOCK_SEPARATION_RADIUS: separation += offset.normalized() / dist # Alignment: match the average heading of neighbors heading_sum += neighbor._get_agent_forward() # Cohesion: drift toward the average position of neighbors position_sum += neighbor.global_position count += 1 if count == 0: _rotation_wander(delta_passed) _move_forward(delta_passed, RATE_MOVE) return var alignment: Vector2 = heading_sum / count var cohesion: Vector2 = (position_sum / count) - global_position

is_instance_valid guards against a neighbor that got freed (removed from the scene) since the last time it entered range; without it, calling a method on a freed node would error. _get_agent_forward() is the exact same method every agent already has from last week, reused here to read a neighbor's current heading rather than reimplementing it.

Part 4. Combining Three Votes

Each rule above produced one raw vector. Combining them isn't a physical force sum, each rule instead gets normalized down to a pure direction first, then scaled by its own weight, so a rule's influence is controlled directly by its weight constant rather than by how large its raw vector happened to be:

agent.gd GDScript
const FLOCK_SEPARATION_WEIGHT: float = 1.6 const FLOCK_ALIGNMENT_WEIGHT: float = 1.0 const FLOCK_COHESION_WEIGHT: float = 0.9 var desired: Vector2 = Vector2.ZERO # Instead of overwriting or aggressively adding normalized vectors, # accumulate the weighted behaviors naturally if separation.length_squared() > 0.0: desired += separation.normalized() * FLOCK_SEPARATION_WEIGHT if alignment.length_squared() > 0.0: desired += alignment.normalized() * FLOCK_ALIGNMENT_WEIGHT if cohesion.length_squared() > 0.0: desired += cohesion.normalized() * FLOCK_COHESION_WEIGHT if desired.length_squared() > 0.01: # Cruise at maximum movement speed var final_desired: Vector2 = desired.normalized() * RATE_MOVE _apply_velocity(delta_passed, final_desired) else: # If no distinct steering desired, smoothly friction out to zero or wander _apply_velocity(delta_passed, Vector2.ZERO)

That last line is worth pausing on: flocking calls _apply_velocity, the exact same method Seek, Arrive, and Flee already use. Three neighbor-reactive rules blended together are, mechanically, just another way of answering "what velocity do I want right now," same as chasing a single target was.

Part 5. Smoothing It Out

_apply_velocity itself needs one real change at this point, though. Up to now it snapped velocity instantly to whatever was desired; fine for one agent chasing one target, but a boid recomputes its desired direction from a shifting set of neighbors every single frame, and instant snapping to a constantly-changing target looks jittery fast, especially multiplied across a whole flock.

agent.gd GDScript
func _apply_velocity(delta_passed: float, desired_velocity: Vector2) -> void: # 1. Smoothly transition the velocity (Inertia/Acceleration) # Lower weight (e.g., 5.0) = wider, smoother turns. Higher = sharper turns. var acceleration_speed: float = 8.0 velocity = velocity.lerp(desired_velocity, acceleration_speed * delta_passed) # 2. Smoothly rotate the agent to face where it's going if velocity.length_squared() > 0.01: var target_rotation: float = Vector2(0, -1).angle_to(velocity) # lerp_angle prevents the agent from spinning 360 degrees when crossing PI/-PI var rotation_speed: float = 10.0 rotation = lerp_angle(rotation, target_rotation, rotation_speed * delta_passed) global_position += velocity * delta_passed

velocity.lerp(desired_velocity, ...) eases the actual velocity toward whatever's desired instead of snapping to it, and lerp_angle does the same for rotation, specifically because lerp_angle knows to take the short way around when an angle crosses the wraparound point (from just under 180 degrees to just over negative 180, for instance), where a naive lerp on the raw numbers would spin the wrong way. This change affects Seek, Arrive, and Flee too, since they all call the same method; go back and try them again once this is in, they should all feel a little smoother than before.

Part 6. Spawning a Flock

Testing this with two hand-placed agents won't show much; flocking needs an actual flock. Attach a new script to the Environment root itself:

environment.gd GDScript
extends Node2D const AGENT_SCENE: PackedScene = preload("res://scenes/agent.tscn") const AGENT_COUNT: int = 10 const SPAWN_RADIUS: float = 500.0 # Populate with agents const MIN_DISTANCE: float = 50.0 # Adjust this value as needed const MAX_ATTEMPTS: int = 100 # Prevents infinite loops if the area is full func _ready(): for i in range(AGENT_COUNT): var agent: Agent2D = AGENT_SCENE.instantiate() var valid_position: bool = false var spawn_pos: Vector2 = Vector2.ZERO # Attempt to find a clear spot for attempt in range(MAX_ATTEMPTS): # 1. Pick a random position spawn_pos = Vector2( randf_range(-SPAWN_RADIUS, SPAWN_RADIUS), randf_range(-SPAWN_RADIUS, SPAWN_RADIUS) ) # 2. Check distance against all agents already added to the tree var too_close: bool = false for other_agent in get_children(): if other_agent is Agent2D: # distance_to is faster than manually calculating distances if spawn_pos.distance_to(other_agent.position) < MIN_DISTANCE: too_close = true break # Stop checking other agents, this position failed # 3. If the spot is clear, we found our position if not too_close: valid_position = true break # Optional: Skip spawning this agent if the map is too crowded if not valid_position: push_warning("Could not find a valid spawn position for agent ", i) agent.queue_free() # Free the unused instance to prevent memory leaks continue # Apply properties and add to scene agent.position = spawn_pos agent.rotation = randf_range(0.0, TAU) agent.color = Color(randf_range(0.4, 0.9), randf_range(0.4, 0.9), randf_range(0.4, 0.9), 1.0) agent.steering_mode = Agent2D.SteeringMode.FLOCK add_child(agent)

Ten agents, spawned at random positions at least MIN_DISTANCE apart (retrying up to MAX_ATTEMPTS times per agent so a crowded spawn area doesn't loop forever), each a random color, each set to FLOCK. Since ten small agents spread across a 1000-pixel spawn area are hard to see at normal zoom, set the Camera2D's Zoom to something like (0.2, 0.2) so the whole flock fits on screen.
