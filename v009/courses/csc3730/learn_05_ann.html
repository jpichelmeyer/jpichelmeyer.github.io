Worth saying plainly before starting: none of the three agents in this project's simulation literally use a neural network. Checker uses Naive Bayes, Sentry uses plain linear regression, the aliens use a Q-table. But Sentry's model turns out to already be almost exactly a neural network's smallest possible case, and stretching it into one is the fastest honest way to see what a real network actually adds.

Part 1. You've Already Trained One Neuron

Recall Sentry's entire model, from last lesson:

sentry_agent.gd GDScript
func predict_lead(distance:float) -> float: return weights[0] + weights[1] * (distance / 100.0)

That's exactly one artificial neuron: take an input, multiply it by a learned weight, add a learned bias, and that's the output. weights[1] is a connection weight; weights[0] is a bias term. And the training procedure, gradient descent nudging each weight opposite the direction of the error, is the exact same procedure a full network uses, just applied to one neuron instead of thousands. A neural network isn't a different training method from what you've already implemented; it's more of the same neuron, arranged into layers, with one extra ingredient this single neuron doesn't have.

Part 2. The Missing Ingredient: Nonlinearity

Stack multiple layers of neurons like Sentry's, each just computing a weighted sum, and the whole stack collapses back down to being equivalent to one single linear neuron; layering plain weighted sums on top of each other doesn't add any expressive power at all. What actually makes depth useful is an activation function applied after each neuron's weighted sum, a simple nonlinear function that breaks that collapse.

Two extremely common choices:

  • ReLU (rectified linear unit): output the input directly if it's positive, otherwise output zero. Simple, cheap, and the default choice in most modern hidden layers.
  • Sigmoid: squashes any input into a value between 0 and 1, historically common, and still a natural fit for a network's final output when that output needs to be read as a probability, like Checker's alien/human decision could be, in a neural version of Checker.

Part 3. Layers

A tiny fully-connected network: three inputs, four hidden neurons (each a weighted sum plus an activation function), one output neuron. Sentry's model is the degenerate case of this picture with one input, no hidden layer, and a linear (no-op) activation on the output.

Every neuron in one layer connects to every neuron in the next; each of those connections carries its own weight, learned independently. The input layer is just the raw features going in (for a neural Checker: head tone, shirt color, pants color). Any layer between input and output is a hidden layer, doing the actual work of combining features into something more useful than the raw inputs were on their own. The output layer produces the final prediction, shaped to match the problem: one neuron with a linear activation for a regression output like Sentry's; one neuron with a sigmoid activation for a yes/no classification like Checker's.

Part 4. Training: Backpropagation

Sentry's update rule could directly compute how much to adjust each of its two weights, because both weights had an immediate, direct effect on the one output. A hidden layer's weights are several steps removed from the final output, so the question "how much did this one weight, buried inside a hidden layer, contribute to the final error" isn't immediately obvious the way it was for Sentry.

Backpropagation answers that question by working backward from the output error, layer by layer, using the chain rule from calculus to split credit (or blame) for that error back across every weight that contributed to it, however many layers removed. Once each weight's share of the blame is known, the update itself is the same gradient descent step Sentry already uses: current weight, minus the learning rate, times that weight's share of the error. Backpropagation is what computes that share for a whole network at once; it's not a different training algorithm from gradient descent, it's the piece that makes gradient descent possible once a network is more than one neuron deep.

Part 5. What a Neural Checker or Sentry Would Actually Buy

Naive Bayes assumes features don't interact; a hidden layer can learn that a specific combination of head tone and shirt color together is suspicious in a way neither feature is on its own, something Checker's current model structurally can't represent. Sentry's straight line assumes lead grows linearly with distance forever; a hidden layer could learn a curved relationship instead, if the real one weren't actually a straight line. Neither upgrade is free: more parameters need more training data to fit well, and a network large enough to matter needs more compute than a frequency table or a two-number line ever did. For problems this small, that tradeoff is exactly why the project's actual agents use the simpler models they do.
