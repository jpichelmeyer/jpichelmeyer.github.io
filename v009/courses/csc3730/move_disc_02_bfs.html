The grid marks every cell as walkable or blocked, which is a graph, but nothing has actually searched it yet. This lesson does: given a start cell and a goal cell, find some sequence of walkable neighbors connecting them, using breadth-first search.

Part 1. Breadth-First Search

Breadth-first search explores outward one ring at a time: check every neighbor of the start, then every neighbor of those, then the next ring out, and so on, never revisiting a cell it's already seen. Because every step in this grid costs the same (one cell), the first time BFS reaches the goal, it's guaranteed to have found a shortest path, no shorter route could exist without a ring being visited out of order. Add this to agent.gd:

agent.gd GDScript
func _path_find_bfs() -> Array: """ return Array[Vector2i], Array[Vector2i] path , searched (not in path) """ var empty_path: Array[Vector2i] = [] var empty_searched: Array[Vector2i] = [] var ret: Array = [empty_path, empty_searched] # Nullity check if target == null or path_grid == null: return ret var cell_target: Vector2i = path_grid.world_to_cell(target.global_position) var cell_self: Vector2i = path_grid.world_to_cell(global_position) # Trivial case: already there if cell_self == cell_target: var trivial_path: Array[Vector2i] = [cell_self] var trivial_searched: Array[Vector2i] = [cell_self] return [trivial_path, trivial_searched] var directions: Array[Vector2i] = [ Vector2i(1, 0), Vector2i(-1, 0), Vector2i(0, 1), Vector2i(0, -1) ] var checked = [cell_self] var frontier: Array[Vector2i] = [cell_self] var came_from: Dictionary = {cell_self: cell_self} var found: bool = false while not frontier.is_empty(): var current: Vector2i = frontier.pop_front() if current == cell_target: found = true break for dir in directions: var next: Vector2i = current + dir # Skip if out of bounds, blocked, or already visited if next.x < 0 or next.x >= path_grid.grid_width: continue if next.y < 0 or next.y >= path_grid.grid_height: continue if not path_grid.is_walkable(next): continue if came_from.has(next): continue came_from[next] = current frontier.append(next) checked.append(next) if not found: return ret # Walk backwards from target to start, then reverse var path_array: Array[Vector2i] = [] var step: Vector2i = cell_target while step != cell_self: path_array.append(step) step = came_from[step] path_array.append(cell_self) path_array.reverse() var searched:Array[Vector2i] = [] for cell in checked: if cell not in path_array: searched.append(cell) return [path_array, searched]

A few things worth noticing about how this is actually written: the four directions and the bounds/walkable checks are inlined directly in the loop rather than pulled into a separate helper, one function, everything visible in one place. frontier is the queue of cells still waiting to be explored, always pulled from the front (pop_front()), which is what keeps the search expanding ring by ring instead of racing down one path first. came_from does double duty: a cell being a key in it means "already seen, don't re-queue," and its value (which cell led here) is exactly what's needed to walk the path back afterward. checked remembers every cell that got looked at, not just the ones on the final path, that becomes searched once the path cells are filtered back out, and it's what lets you actually see how much of the grid BFS explored, not just where it ended up.

Part 2. Following the Path

Once a route exists as a list of cells, walking it reuses last week's _apply_velocity exactly as it already is, aimed at one waypoint at a time instead of a single fixed target.

agent.gd GDScript
const PATH_WAYPOINT_RADIUS: float = 4.0 var _travel_path: Array[Vector2i] = [] var _travel_index: int = 0 func _steer_arrive_at(delta_passed: float, destination: Vector2, speed: float) -> bool: """Steers toward destination at up to `speed`. Returns true once arrived.""" var offset: Vector2 = destination - global_position var dist: float = offset.length() if dist < PATH_WAYPOINT_RADIUS: velocity = Vector2.ZERO return true _apply_velocity(delta_passed, offset.normalized() * speed) return false func _follow_path(delta_passed: float) -> void: if path_grid == null or _travel_index >= _travel_path.size(): _travel_path.clear() _travel_index = 0 velocity = Vector2.ZERO return var waypoint_world: Vector2 = path_grid.cell_to_world_center(_travel_path[_travel_index]) var arrived: bool = _steer_arrive_at(delta_passed, waypoint_world, move_speed) if arrived: _travel_index += 1 if _travel_index >= _travel_path.size(): _travel_path.clear() _travel_index = 0 velocity = Vector2.ZERO func _start_following(path: Array[Vector2i]) -> void: _travel_path = path _travel_index = 0

Add a move_speed export if you don't already have one (150.0 is a reasonable default), and check _travel_path at the top of _process, ahead of everything else: if a path is being followed, follow it; otherwise fall back to whatever this agent would normally be doing.

agent.gd GDScript
@export var move_speed: float = 150.0 func _process(delta: float) -> void: if not _travel_path.is_empty(): _follow_path(delta) elif target != null: _rotate_toward_target() else: _rotation_wander(delta) _move_forward(delta, RATE_MOVE)

Part 3. Wiring Up a Button

Add a Search: BFS button to the Camera's CanvasLayer, and give Agent a handler for it:

agent.gd GDScript
func _on_search_bfs_pressed() -> void: if target != null and path_grid != null: var ret = _path_find_bfs() path_grid.display_path(ret[0], Color(0.5, 0.5, 0.75), ret[1]) _start_following(ret[0])

display_path(path, highlight_color, searched) is a method already sitting on PathGrid: it redraws the grid with the path cells tinted highlight_color and a small dot over every searched cell that isn't on the final path, exactly the yellow-path, blue-dot look in the diagram above. _start_following is what actually makes the agent move, hand it the same path display_path is showing.

Set your agent's target to something on the far side of the obstacle, press Generate Grid, then Search: BFS. The agent should route cleanly around the obstacle rather than walking into it, and the grid should show both the route and everywhere BFS looked along the way.
