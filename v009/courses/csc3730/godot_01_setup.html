Web source

  1. Go to the page for Godot 4.6.2-stable and find the area of the page associated with your operating system.

Linux

  1. On the download page, click the Standard button to download the 64-bit Linux binary (Godot_v4.6-stable_linux.x86_64.zip), which is a self-contained executable there's no installer.
  2. Unzip the downloaded file to a folder of your choice, e.g. ~/Applications/Godot.
  3. Make the file executable. Right-click the file → Properties → Permissions → check "Allow executing file as program", or from a terminal run: chmod +x Godot_v4.6-stable_linux.x86_64
  4. Double-click the file (or run it from the terminal) to launch the Godot Project Manager.
  5. Optional: rename the file to Godot, move it to /opt/godot or ~/.local/bin, and add it to your PATH so you can launch it by typing godot in a terminal.

MacOS

  1. Download the Standard macOS build (Godot_v4.6-stable_macos.universal.zip). It works on both Intel and Apple Silicon Macs.
  2. Unzip the file. This produces a Godot.app application.
  3. Drag Godot.app into your Applications folder.
  4. Since Godot isn't downloaded from the App Store, the first time you open it macOS will warn that it's from an unidentified developer.
    • Right-click (or Control-click) Godot.app and choose Open, then confirm Open in the dialog that appears. You only need to do this once.
    • Alternatively, go to System Settings → Privacy & Security and click Open Anyway next to the Godot warning.
  5. Godot will now launch normally. You can open it going forward from Launchpad or Applications like any other app.

Windows

  1. Download the Standard 64-bit Windows build (Godot_v4.6-stable_win64.exe.zip).
  2. Unzip the file. This produces a single Godot_v4.6-stable_win64.exe file. That's it. There's no installer to run.
  3. Move the .exe to a permanent folder, e.g. C:\Godot\.
  4. Double-click the .exe to launch Godot.
    • If Windows SmartScreen shows a warning ("Windows protected your PC"), click More info then Run anyway.
  5. Optional: right-click the .exe and choose Pin to Start or Send to → Desktop (create shortcut) for easy access later.
