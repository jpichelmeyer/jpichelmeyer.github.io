Web source

  1. Go to thonny.org. The top-right corner has download links for each operating system.

Linux

  1. Open a terminal and run the official install script: bash <(curl -s https://thonny.org/installer-for-linux) This downloads a self-contained copy of Thonny into your home folder (it won't interfere with any Python already on your system) and adds it to your applications menu.
  2. Alternative: most distributions (including Mint) package Thonny directly, though usually an older version: sudo apt install thonny
  3. Launch it from your applications menu, or type thonny in a terminal.

MacOS

  1. On the download page, click the Mac link. This downloads a .pkg installer (e.g. thonny-4.1.7.pkg).
  2. Double-click the downloaded file and click through Continue → Agree → Install. This installs Thonny and its own bundled Python together, so you don't need Python installed separately.
  3. The first time you open it, macOS may warn it's from an unidentified developer. Right-click (or Control-click) the Thonny app and choose Open, then confirm in the dialog. You only need to do this once.
  4. Launch Thonny going forward from Launchpad or Applications like any other app.

Windows

  1. On the download page, click the Windows link. This downloads an .exe installer (e.g. thonny-4.1.7.exe).
  2. Double-click the file to run it. Accept the license, and choose Install for me only unless you have a specific reason to install for all users.
  3. Check the box for a desktop icon if you'd like one, then click through to finish. This bundles Python together with Thonny, so there's nothing else to install first.
  4. If Windows SmartScreen shows a warning ("Windows protected your PC"), click More info then Run anyway.
  5. Launch Thonny from the Start menu or the desktop icon.

First Run

  1. The first time Thonny opens, it may ask you to pick an initial settings style — Standard is fine.
  2. You'll see two main areas: the editor (top), where you write code, and the Shell (bottom), where output appears and you can run Python interactively line-by-line.
  3. Type print("hello, world") into the editor, save the file (Ctrl/Cmd+S) as hello.py, then click the green Run button (or press F5). You should see the greeting appear in the Shell below.
