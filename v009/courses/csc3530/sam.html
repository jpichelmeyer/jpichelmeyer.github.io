Before building anything, we need one shared way to talk about what an agent is, one that still applies whether the agent uses search, rules, cases, or analogies. In this course that vocabulary is the Situated Agent Model, or SAM. If you have taken CSC 3730 or CSC 4110 you have seen SAM before. This lesson gives the cognitive edition: the same four units, with Memory opened up into the kinds that cognitive scientists distinguish, and one new unit, the Monitor, for an agent that can think about its own thinking.

Part 1. Agent and Environment

SAM starts from one split. There is an Agent, and there is an Environment the agent is situated in. The agent never has direct access to the environment's true state. It knows only what it can observe, and it can change the world only through the actions it is able to take. Everything happens in a loop: observe, decide, act, and observe again, because the action changed what there is to observe.

That split matters even for a puzzle solver. An ARC task looks like it hands you everything, but it does not: it hands you numbers in a grid. Objects, symmetry, "the odd one out," and "moves until it touches" are not in the file. The agent has to build them. Whatever it builds is its picture of the environment, not the environment itself.

Part 2. The Units Inside the Agent

Inside the agent, the loop breaks into units, each with one job. The colours are the same in every SAM diagram this term.

  • Perceptor: detects observables and turns them into representations the rest of the agent can reason with. In robotics courses this means sensors and filtering. Here it means interpretation: turning a grid of integers into objects with colours, sizes, positions, and relations. Knowledge-based AI holds that most of the difficulty of a problem lives in this step. A good representation makes the answer easy to see.
  • Memory: holds information over time. Cognitive science splits it in two:
    • Working memory: the situation model, meaning what the agent believes about the current problem right now. It is small and changes constantly.
    • Long-term memory: what persists across problems. It has three kinds: semantic memory (concepts and facts: frames, semantic networks), episodic memory (specific past experiences: cases), and procedural memory (how to do things: rules, methods).
  • Decider: takes what is in working memory, draws on long-term memory, and chooses what to do. Most of this course is a tour of different Deciders: generate and test, means-ends analysis, production rules, case-based reasoning, analogy, planning, constraint propagation.
  • Actuator: carries out the chosen action. It is the only unit allowed to change anything outside the agent. For ARC, that means writing the output grid.

Two additions make this a cognitive agent:

  • Learning is an arrow, not a unit: the Decider writes back into long-term memory. Recording a case, adding a rule, and refining a concept are all writes to long-term memory.
  • The Monitor watches the Decider rather than the world. Is this line of reasoning working? Is my answer consistent with everything I was shown? Should I try a different method? That is metacognition, and the course's third module is about it.
The Situated Agent Model, cognitive edition. The Perceptor builds representations from observables; the Decider reasons over working memory with help from long-term memory and can write new knowledge back into it (learning); the Actuator carries the chosen action into the Environment. The Monitor watches and steers the Decider. The dashed arrow is a reflex: perception wired directly to action with no deliberation.

Part 3. Metacognition Is SAM, Applied to Itself

Here is a useful way to think about the Monitor. It is a second, smaller agent whose environment is the first agent's reasoning. It perceives traces of that reasoning (which hypotheses were tried, which failed, how long it has been going on). It decides whether things are on track. It acts by changing what the reasoning does next: switching strategy, adjusting a goal, or giving up and guessing. Psychologists Thomas Nelson and Louis Narens described human metacognition in exactly these terms: an object level that does the task, a meta level that holds a model of the object level, with monitoring flowing up and control flowing down.

Two loops. The object-level agent is situated in the task. The Monitor is situated in the object-level agent.
Human cognition connection

You do this constantly. Halfway through an ARC task you think "this is taking too long; maybe it is not about colour at all." That thought has no content about the grid. It is about your own search, and it changes what you do next. Good problem solvers are distinguished less by faster search than by better monitoring.

Part 5. A Tiny SAM Agent in Python

Here is a complete SAM agent for a small problem: continuing a number sequence such as 2, 4, 6, 8, ?. Like ARC, this is induction from examples. The agent has to find a rule that explains everything it was shown, then apply it once more. Each unit is its own class.

sequence_agent.py: Perceptor Python
class Perceptor: def perceive(self, puzzle): """Turn raw text into a symbolic percept: a list of ints.""" parts = [p.strip() for p in puzzle.split(',')] return [int(p) for p in parts if p != '?']

The Perceptor's job is interpretation. It throws away the commas and the question mark and keeps a symbolic percept: a list of integers.

sequence_agent.py: Memory Python
class Memory: def __init__(self): self.working = {} # the current situation self.procedural = { # long-term: rules it knows how to apply 'add a constant': self.add_rule, 'multiply by a constant': self.mul_rule, } self.episodic = [] # long-term: a log of past episodes @staticmethod def add_rule(seq): d = seq[1] - seq[0] return lambda i: seq[0] + d * i @staticmethod def mul_rule(seq): if seq[0] == 0: return None r = seq[1] // seq[0] return lambda i: seq[0] * r ** i

Memory has a working part (the current sequence) and two long-term parts: procedural rules it knows how to apply, and an episodic log. Each rule takes the observed sequence and returns a function from position i to value.

sequence_agent.py: Decider, Actuator, Monitor Python
class Decider: def decide(self, memory, monitor): seq = memory.working['seq'] for name, make in memory.procedural.items(): rule = make(seq) if rule and monitor.explains(rule, seq): # metacognitive check return name, rule(len(seq)) return None, None class Actuator: def act(self, name, answer): if name is None: print(' answer: I do not know this kind of sequence') else: print(f' answer: {answer} (rule: {name})') class Monitor: """Watches the Decider instead of the world. Does the rule it picked actually reproduce every number we were shown?""" def explains(self, rule, seq): return all(rule(i) == x for i, x in enumerate(seq)) def reflect(self, memory, name): memory.episodic.append((memory.working['seq'], name)) if name is None: print(' monitor: no rule fit; this episode is marked for learning')

Notice where the check lives. The Decider proposes; the Monitor judges whether a proposed rule reproduces every observed number. For 1, 4, 9, 16, the "add a constant" rule built from the first two terms is "add 3", which predicts 7 for the third term instead of 9, so the Monitor rejects it. Without the Monitor the agent would confidently answer 19.

sequence_agent.py: the agent and a learning step Python
class SequenceAgent: def __init__(self): self.perceptor, self.memory = Perceptor(), Memory() self.decider, self.actuator, self.monitor = Decider(), Actuator(), Monitor() def step(self, puzzle): print(puzzle) self.memory.working['seq'] = self.perceptor.perceive(puzzle) name, answer = self.decider.decide(self.memory, self.monitor) self.actuator.act(name, answer) self.monitor.reflect(self.memory, name) agent = SequenceAgent() for puzzle in ['2, 4, 6, 8, ?', '3, 6, 12, 24, ?', '1, 4, 9, 16, ?']: agent.step(puzzle) # Learning = writing a new rule into long-term (procedural) memory. def square_rule(seq): return lambda i: (i + 1) ** 2 agent.memory.procedural['squares'] = square_rule print('-- after learning --') agent.step('1, 4, 9, 16, ?') print('episodes remembered:', len(agent.memory.episodic))

Part 6. The Semester Agent: SAM for ARC

Here is how the units map onto ARC:

SAM for ARC-AGI. The training pairs give the Monitor something no ordinary puzzle gives: a built-in way to test hypotheses before answering. The grader outside the agent only says right or wrong, and only after the attempts are used.

arc_agent.py is the starting point for your semester project. Every unit is deliberately weak. The Decider knows only the eight symmetries of a square (identity, two flips, two transposes, three rotations).

arc_agent.py: Perceptor and Memory Python
class Perceptor: """Raw JSON grids in, a symbolic percept out.""" def describe(self, grid): return {'grid': grid, 'size': dims(grid), 'background': background(grid), 'objects': find_objects(grid)} def perceive(self, task): return {'train': [(self.describe(p['input']), self.describe(p['output'])) for p in task['train']], 'test': [self.describe(p['input']) for p in task['test']]} class Memory: """Working memory holds the current task; long-term memory holds episodes (which method solved which task) and survives between runs.""" def __init__(self, path='agent_memory.json'): self.path = path self.working = None self.episodes = [] if os.path.exists(path): with open(path) as f: self.episodes = json.load(f) def remember(self, task_id, methods): self.episodes.append({'task': task_id, 'methods': methods}) def save(self): with open(self.path, 'w') as f: json.dump(self.episodes, f, indent=1)
arc_agent.py: Decider, Monitor, Actuator Python
class Decider: """Proposes candidate transformations. Week 1: the eight symmetries of a square. Later weeks: rules, search, cases, analogies...""" def __init__(self): self.hypotheses = [('identity', lambda g: [r[:] for r in g]), ('flip_h', flip_h), ('flip_v', flip_v), ('transpose', transpose), ('rotate90', rotate90), ('rotate180', rotate180), ('rotate270', rotate270), ('anti_transpose', lambda g: rotate180(transpose(g)))] def propose(self, percept): yield from self.hypotheses class Monitor: """Metacognition, week 1: never trust a hypothesis that fails a train pair.""" def verify(self, fn, percept): try: return all(fn(i['grid']) == o['grid'] for i, o in percept['train']) except Exception: return False class Actuator: """Turns chosen hypotheses into up to two attempts per test input, in the ARC Prize submission format.""" def act(self, chosen, percept): answers = [] for t in percept['test']: guesses = [fn(t['grid']) for _, fn in chosen][:2] while len(guesses) < 2: guesses.append(t['grid']) # fallback: copy the input answers.append({'attempt_1': guesses[0], 'attempt_2': guesses[1]}) return answers
arc_agent.py: putting it together Python
class ARCAgent: def __init__(self): self.perceptor, self.memory = Perceptor(), Memory() self.decider, self.monitor, self.actuator = Decider(), Monitor(), Actuator() def solve(self, task_id, task): percept = self.perceptor.perceive(task) self.memory.working = percept chosen = [(n, f) for n, f in self.decider.propose(percept) if self.monitor.verify(f, percept)][:2] self.memory.remember(task_id, [n for n, _ in chosen]) return self.actuator.act(chosen, percept), [n for n, _ in chosen] def evaluate(agent, folder='data/training'): solved = [] for name in sorted(os.listdir(folder)): task_id = name[:-5] task = load_task(os.path.join(folder, name)) answers, methods = agent.solve(task_id, task) right = all(t['output'] in (a['attempt_1'], a['attempt_2']) for t, a in zip(task['test'], answers)) if right: solved.append((task_id, methods[0])) return solved if __name__ == '__main__': agent = ARCAgent() solved = evaluate(agent) print(f'solved {len(solved)} of 400 training tasks') for task_id, method in solved: print(' ', task_id, method)
