A semantic network spreads knowledge across many little links. A frame gathers the knowledge about one kind of thing into one structure: a named bundle of slots, each with a typical filler and rules about what may go there. Marvin Minsky proposed frames in 1974 as a theory of how people bring the right expectations to a new situation. Walk into a restaurant, a classroom, or an ARC task, and a frame tells you what to look for before you have looked.

Part 1. Slots, Fillers, and Expectations

Here is the frame for a surgery event, taken from the ontology in this week's McShane reading. Each slot has several facets:

The SURGERY frame, after McShane, Nirenburg & English (2024), p. 50. default: the typical filler. sem: the normal type restriction. relaxable-to: possible but unusual. if-needed: a procedure (a "demon") that computes a value on request.

Facets give an agent graded expectations. Told that a vet operated on a dog, the agent accepts both fillers (a vet is medical personnel, a dog is an animal), and if asked where, it answers "an operating room" by default. Told that a farmer operated in a barn, it accepts the sentence but notes that two expectations were violated. Told that the surgery took place "in the dog," it rejects the filler outright, since a dog is not a place.

Frames add three things that a flat list of facts does not have:

  • Defaults let the agent assume what is typical and override it when told otherwise.
  • Inheritance: a frame can be a specialization of a more general frame and inherit its slots. SURGERY inherits time from EVENT.
  • Procedural attachment: a slot can hold a small procedure (an if-needed or if-added demon) instead of a value.
Looking up a slot. The agent checks the instance first, then the frame, then the frame's parents. The first value found wins, which is how a stated fact overrides a default.
Human cognition connection

Frames descend from Frederic Bartlett's schemas (1932). Bartlett had English students retell a Native American folk tale, "The War of the Ghosts," and found that their retellings drifted toward their own cultural expectations: unfamiliar details dropped out or turned into familiar ones. Brewer and Treyens (1981) left people waiting briefly in a graduate student's office and then asked what they had seen. Many "remembered" books, which an office should have but this one did not. Defaults fill memory as well as perception, sometimes falsely.

A frame is a node of a semantic network together with its outgoing labelled edges. The packaging makes it natural to attach defaults and demons to slots.

Part 2. A Frame-Based Interpreter

The agent below interprets short statements about surgeries. Its long-term memory has a small concept hierarchy (to check sem constraints) and two frames.

frame_agent.py: a concept hierarchy Python
ISA = { # a tiny concept hierarchy: child -> parent 'surgeon': 'medical-personnel', 'vet': 'medical-personnel', 'nurse': 'medical-personnel', 'medical-personnel': 'human', 'farmer': 'human', 'human': 'animal', 'dog': 'animal', 'operating-room': 'medical-building', 'clinic': 'medical-building', 'medical-building': 'place', 'barn': 'place', } def is_a(x, y): while x is not None: if x == y: return True x = ISA.get(x) return False
frame_agent.py: frames with facets and inheritance Python
class Frame: """A frame is a named bundle of slots. Each slot has facets: default the typical filler sem the normal type restriction relaxable_to what is possible, though unusual if_needed a demon that computes a value only when asked""" def __init__(self, name, parent=None, **slots): self.name, self.parent, self.slots = name, parent, slots def facet(self, slot, facet): f = self while f is not None: # inheritance up the chain if slot in f.slots and facet in f.slots[slot]: return f.slots[slot][facet] f = f.parent return None def slot_names(self): names, f = [], self while f is not None: names += [s for s in f.slots if s not in names] f = f.parent return names EVENT = Frame('event', time={'if_needed': lambda inst: 'some time in the past'}) SURGERY = Frame('surgery', parent=EVENT, agent={'default': 'surgeon', 'sem': 'medical-personnel', 'relaxable_to': 'human'}, theme={'default': 'human', 'sem': 'animal'}, location={'default': 'operating-room', 'sem': 'medical-building', 'relaxable_to': 'place'})

An instance is a filled-in copy of a frame. Filling a slot checks the filler against the facets; reading a slot falls back from stated values to demons to defaults.

frame_agent.py: instances Python
class Instance: """A filled-in copy of a frame: one particular event.""" def __init__(self, frame, **fillers): self.frame, self.fillers, self.notes = frame, {}, [] for slot, value in fillers.items(): self.fill(slot, value) def fill(self, slot, value): sem, relax = self.frame.facet(slot, 'sem'), self.frame.facet(slot, 'relaxable_to') if sem is None or is_a(value, sem): self.fillers[slot] = value elif relax and is_a(value, relax): self.fillers[slot] = value self.notes.append(f'{slot}={value} is possible but unusual (expected a {sem})') else: self.notes.append(f'{slot}={value} REJECTED: not even a {relax or sem}') def get(self, slot): if slot in self.fillers: return self.fillers[slot], 'stated' demon = self.frame.facet(slot, 'if_needed') if demon: return demon(self), 'computed by demon' default = self.frame.facet(slot, 'default') return default, 'assumed by default' def report(self): for slot in self.frame.slot_names(): value, how = self.get(slot) print(f' {slot:9} {value:16} ({how})') for n in self.notes: print(' note:', n)

The "how" column is the point. Because every value records where it came from (stated, computed, or assumed), the agent can tell you which of its beliefs are guesses. That is the beginning of the explainability McShane and colleagues argue for.

Part 3. A Taste of ARC: Frames for Pairs and Tasks

For ARC, a useful frame is one that describes a train pair: same size or not, size ratio, colours added or lost, number of objects, how many cells changed. Many of these are expensive to compute and only sometimes needed, so they are if-needed demons.

arc_frames.py: a pair frame with demons Python
class PairFrame: """One train pair, described by slots. Cheap slots are filled at once; expensive ones are computed by if-needed demons the first time asked.""" DEMONS = { 'same_size': lambda p: dims(p.inp) == dims(p.out), 'size_ratio': lambda p: (len(p.out) / len(p.inp), len(p.out[0]) / len(p.inp[0])), 'new_colors': lambda p: colors(p.out) - colors(p.inp), 'lost_colors': lambda p: colors(p.inp) - colors(p.out), 'n_objects_in': lambda p: len(find_objects(p.inp, bg=0)), 'n_objects_out': lambda p: len(find_objects(p.out, bg=0)), 'cells_changed': lambda p: (sum(a != b for ra, rb in zip(p.inp, p.out) for a, b in zip(ra, rb)) if dims(p.inp) == dims(p.out) else None), 'out_symmetric': lambda p: p.out == flip_h(p.out) or p.out == flip_v(p.out), } def __init__(self, pair): self.inp, self.out = pair['input'], pair['output'] self.slots = {} # filled lazily def __getitem__(self, slot): if slot not in self.slots: self.slots[slot] = self.DEMONS[slot](self) return self.slots[slot]
A PairFrame for the first train pair of a416b8f3 (the input placed twice side by side). Slots are filled only when asked.

A task frame generalizes over its pair frames. A slot whose value is the same in every train pair is an invariant of the task, and invariants are strong hints. If every pair has size_ratio == (1.0, 2.0), the test output will almost certainly be twice as wide as the test input, and the Decider can throw away any hypothesis that produces a different size.

arc_frames.py: invariants across pairs Python
class TaskFrame: """Generalizes over the pair frames: a slot is an invariant of the task if every train pair has the same value for it.""" def __init__(self, task): self.pairs = [PairFrame(p) for p in task['train']] def invariants(self, slots): found = {} for s in slots: values = [p[s] for p in self.pairs] if all(v == values[0] for v in values): found[s] = values[0] return found slots = list(PairFrame.DEMONS) for tid in ['0ca9ddb6', 'a416b8f3', 'aabf363d', 'd631b094']: tf = TaskFrame(load_task(f'data/training/{tid}.json')) print(tid) for s, v in tf.invariants(slots).items(): print(f' {s:14} {v}')

Read the output like a detective. In 0ca9ddb6 the size never changes and colours 4 and 7 always appear: something is being added. In aabf363d there are always two objects in and one out: something is being removed. In d631b094 the output is always symmetric and black disappears. None of these is a solution, but each one rules out most of the possible rules before any search begins.

SAM lens

Frames are long-term semantic memory (the SURGERY frame, a general PairFrame) and working memory (the instances filled in for the current task). The Perceptor fills frames; the Decider reads them; defaults let the agent act on missing information. Use the invariants as a filter in front of your Decider this week.
