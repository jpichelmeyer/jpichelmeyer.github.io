Ask a person "if John gave Mary a book, who has the book?" and the answer is instant. Getting a machine to that answer requires knowing that giving transfers possession, that possession is exclusive for books (but not for news), and a thousand other things nobody ever says out loud. That unstated background is common sense. In ARC, common sense is Chollet's core knowledge: objects persist, things fall, insides are inside. This lesson shows one classic way to organize common-sense knowledge about actions, and then gives your agent a few physical priors.

Reading
  • Bennett, Ch. 22: Commonsense questions and the inner simulation (PDF pp. 353–355 · 3 pages)

Part 1. Primitive Actions

Roger Schank's conceptual dependency theory (1970s) proposed that the meanings of thousands of action verbs reduce to about a dozen primitive actions. "Give," "sell," "hand," and "donate" are all ATRANS (abstract transfer of possession); they differ in details (money changes hands in "sell"), not in their core.

Schank's primitive actions (simplified). Every action verb in a story is rewritten as one or more of these.

The point of primitives is economy of inference. The common-sense consequences of an action are written once, for the primitive, and every verb that reduces to it inherits them. Learn that INGEST puts food inside the eater, and you know it for "ate," "drank," "devoured," and verbs you have never seen, once you know they are INGEST.

Many verbs, one primitive, one set of inferences.
Human cognition connection

Common sense starts very early. In violation-of-expectation experiments (Elizabeth Spelke, Renée Baillargeon and others), infants a few months old look longer at events that break physical rules: a ball rolling through a solid wall, an object vanishing from behind a screen. They are surprised, so they expected otherwise. This week's Bennett reading argues that much of human common sense comes from running an inner simulation of the world, and that language models answer common-sense questions by a different route (statistics over text), which works surprisingly often and fails in revealing ways.

Part 2. A Conceptual-Dependency Agent

cd_agent.py: verbs, primitives, consequences Python
# Many verbs, few primitive actions. Each primitive knows its consequences. VERB_TO_PRIMITIVE = { 'gave': 'ATRANS', 'sold': 'ATRANS', 'handed': 'ATRANS', # transfer of possession 'threw': 'PROPEL', 'tossed': 'PROPEL', # apply force to move 'walked': 'PTRANS', 'drove': 'PTRANS', # change of location 'ate': 'INGEST', 'drank': 'INGEST', 'devoured': 'INGEST', # take into the body 'told': 'MTRANS', 'showed': 'MTRANS', # transfer of information } def consequences(prim, actor, obj, to): """What becomes true and false: the common-sense knowledge attached to each primitive, written once and shared by every verb.""" if prim == 'ATRANS': return {('has', to, obj)}, {('has', actor, obj)} if prim == 'PROPEL': return {('at', obj, to)}, {('has', actor, obj)} if prim == 'PTRANS': return {('at', actor, to)}, {('at', actor, 'home')} if prim == 'INGEST': return {('inside', obj, actor)}, {('exists', obj, 'outside'), ('hungry', actor, None)} if prim == 'MTRANS': # information is copied, not moved return {('knows', to, obj)}, set() return set(), set()

The story runs as a sequence of state changes. Each sentence is reduced to its primitive, and the primitive's consequences update the world model.

cd_agent.py: a story Python
world = {('has', 'john', 'book'), ('has', 'john', 'ball'), ('knows', 'mary', 'news'), ('hungry', 'john', None), ('exists', 'apple', 'outside'), ('at', 'john', 'home')} story = [('john', 'gave', 'book', 'mary'), ('mary', 'told', 'news', 'john'), ('john', 'threw', 'ball', 'sue'), ('john', 'devoured', 'apple', None), ('john', 'walked', None, 'school')] for actor, verb, obj, to in story: prim = VERB_TO_PRIMITIVE[verb] add, delete = consequences(prim, actor, obj, to) world = (world - delete) | add print(' '.join(w for w in [actor, verb, obj, 'to ' + to if to else ''] if w), f' [{prim}]')
cd_agent.py: questions the story never answered directly Python
def ask(q): return 'yes' if q in world else 'no' for question, fact in [('Does Mary have the book?', ('has', 'mary', 'book')), ('Does John still have the book?', ('has', 'john', 'book')), ('Does Mary still know the news?', ('knows', 'mary', 'news')), ('Does John know the news?', ('knows', 'john', 'news')), ('Is John still hungry?', ('hungry', 'john', None)), ('Is John at home?', ('at', 'john', 'home'))]: print(f'{question:32} {ask(fact)}')
Shell output Output
john gave book to mary [ATRANS] mary told news to john [MTRANS] john threw ball to sue [PROPEL] john devoured apple [INGEST] john walked to school [PTRANS] Does Mary have the book? yes Does John still have the book? no Does Mary still know the news? yes Does John know the news? yes Is John still hungry? no Is John at home? no

No sentence said "John no longer has the book" or "Mary still knows the news." Those came from the primitives: ATRANS moves possession (so the giver loses it), MTRANS copies information (so the teller keeps it). Notice also what is missing: the agent believes John is no longer at home, but it has no idea whether Sue caught the ball. Every common-sense system is a long list of such gaps, which is why Doug Lenat's Cyc project spent decades writing down millions of facts.

Part 3. A Taste of ARC: Physical Priors

Chollet designed ARC so that its tasks need only core knowledge. That makes the priors a good list of ready-made hypotheses for an agent to try before searching:

arc_priors.py: gravity Python
def gravity(grid, direction): """Every coloured cell slides as far as it can in one direction, stopping at the edge or at another cell (stacking up).""" g = grid turn = {'down': 0, 'left': 1, 'up': 2, 'right': 3}[direction] for _ in range(turn): # rotate so that "down" is the direction g = [list(r) for r in zip(*g[::-1])] h, w = dims(g) out = [[0] * w for _ in range(h)] for c in range(w): col = [g[r][c] for r in range(h) if g[r][c] != 0] for k, v in enumerate(reversed(col)): out[h - 1 - k][c] = v for _ in range((4 - turn) % 4): # rotate back out = [list(r) for r in zip(*out[::-1])] return out
Task 00d62c1b. Every region enclosed by green becomes yellow.
arc_priors.py: insideness Python
def fill_enclosed(grid, color): """Insideness: black cells that cannot reach the border are inside something. Paint them.""" h, w = dims(grid) outside = set() q = deque((r, c) for r in range(h) for c in range(w) if (r in (0, h - 1) or c in (0, w - 1)) and grid[r][c] == 0) outside.update(q) while q: r, c = q.popleft() for nr, nc in [(r + 1, c), (r - 1, c), (r, c + 1), (r, c - 1)]: if 0 <= nr < h and 0 <= nc < w and grid[nr][nc] == 0 and (nr, nc) not in outside: outside.add((nr, nc)) q.append((nr, nc)) return [[color if v == 0 and (r, c) not in outside else v for c, v in enumerate(row)] for r, row in enumerate(grid)]
arc_priors.py: priors as hypotheses Python
def hypotheses(task): """Core-knowledge priors as ready-made hypotheses. The fill colour is read off the first train pair (whatever appears that was not there).""" for d in ['down', 'up', 'left', 'right']: yield f'gravity {d}', lambda g, d=d: gravity(g, d) p = task['train'][0] new = {v for row in p['output'] for v in row} - {v for row in p['input'] for v in row} for c in new: yield f'fill enclosed with {c}', lambda g, c=c: fill_enclosed(g, c) if __name__ == '__main__': solved = [] for name in sorted(os.listdir('data/training')): task = load_task('data/training/' + name) for label, h in hypotheses(task): if all(h(p['input']) == p['output'] for p in task['train']): if all(h(p['input']) == p['output'] for p in task['test']): solved.append(f'{name[:-5]} ({label})') break print(len(solved), 'tasks:', ', '.join(solved))
Shell output Output
4 tasks: 00d62c1b (fill enclosed with 4), 1e0a9b12 (gravity down), 3906de3d (gravity up), a5313dff (fill enclosed with 1)

Four tasks from two priors. Each prior is a small piece of world knowledge (things fall and stack; regions can be enclosed) that no amount of flipping and cropping would have produced. Common sense in an ARC agent looks like this: a growing library of physical and geometric primitives that a child would take for granted.

SAM lens

Common-sense knowledge sits in long-term semantic and procedural Memory: primitives with their consequences, physical priors with their simulations. The Decider uses it to infer what was never stated; the Perceptor uses it to interpret ("those cells are a container"). Most failures of your agent from here on will be missing common sense.
