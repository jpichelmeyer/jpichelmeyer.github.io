All of our code this term is plain Python, written and run in Thonny, a small editor built for learning. It ships with its own copy of Python, so there is nothing else to install. If you used Thonny in CSC 1100 you can skip to Course Project Folder below.

Web source

  1. Go to thonny.org. The top-right corner has download links for each operating system.

Linux

  1. Open a terminal and run the official install script: bash <(curl -s https://thonny.org/installer-for-linux) This downloads a self-contained copy of Thonny into your home folder (it won't interfere with any Python already on your system) and adds it to your applications menu.
  2. Alternative: most distributions (including Mint) package Thonny directly, though usually an older version: sudo apt install thonny
  3. Launch it from your applications menu, or type thonny in a terminal.

MacOS

  1. On the download page, click the Mac link. This downloads a .pkg installer.
  2. Double-click the downloaded file and click through Continue → Agree → Install. This installs Thonny and its own bundled Python together.
  3. The first time you open it, macOS may warn it's from an unidentified developer. Right-click (or Control-click) the Thonny app and choose Open, then confirm. You only need to do this once.
  4. Launch Thonny going forward from Launchpad or Applications.

Windows

  1. On the download page, click the Windows link. This downloads an .exe installer.
  2. Double-click the file to run it. Accept the license, and choose Install for me only unless you have a reason to install for all users.
  3. Check the box for a desktop icon if you'd like one, then click through to finish.
  4. If Windows SmartScreen shows a warning ("Windows protected your PC"), click More info then Run anyway.
  5. Launch Thonny from the Start menu or the desktop icon.

First Run

  1. The first time Thonny opens, it may ask you to pick an initial settings style; Standard is fine.
  2. You'll see the editor (top), where you write code, and the Shell (bottom), where output appears and you can run Python one line at a time.
  3. Type print("hello, world") into the editor, save it (Ctrl/Cmd+S) as hello.py, then click the green Run button (or press F5).

When you press Run, Thonny runs your script from the folder it is saved in. That is why a path like 'data/training/a416b8f3.json' works, as long as the script sits in the project folder next to data/.

hello_agent.py Python
from arc_utils import load_task, show task = load_task('data/training/a416b8f3.json') for i, pair in enumerate(task['train']): show(pair['input'], f'train {i} input') show(pair['output'], f'train {i} output')

If you see a FileNotFoundError, the script is not saved in the project folder, or the data folder is one level deeper than it should be (a common unzip surprise: data/ARC-AGI-master/data/...).

Thonny Features You Will Use All Term

  • Variables view (View → Variables): shows every variable and its value after a run. Click a grid to see it as a list of lists.
  • The debugger: Debug current script (the bug icon, or Ctrl+F5), then Step over (F6) and Step into (F7). For an agent that reasons in many small steps, watching it think one step at a time is the best way to find out why it chose a wrong answer. This is metacognition done by hand.
  • The Shell: after a run, every variable is still alive in the Shell. Type task['train'][0]['output'] to poke at data without editing your file.
  • Package manager (Tools → Manage packages...): installs extra libraries into Thonny's Python. The course code needs none, but drawing grids in colour is nice.

Optional: Draw Grids in ARC Colours

In Tools → Manage packages..., search for matplotlib and click Install. Then:

draw.py Python
# Optional: draw a grid in ARC colours (needs matplotlib). import matplotlib.pyplot as plt from matplotlib.colors import ListedColormap from arc_utils import load_task ARC_CMAP = ListedColormap(['#000000', '#0074D9', '#FF4136', '#2ECC40', '#FFDC00', '#AAAAAA', '#F012BE', '#FF851B', '#7FDBFF', '#870C25']) def draw(grid, ax, title=''): ax.imshow(grid, cmap=ARC_CMAP, vmin=0, vmax=9) ax.set_xticks([]); ax.set_yticks([]); ax.set_title(title) task = load_task('data/training/0ca9ddb6.json') fig, axes = plt.subplots(2, len(task['train']), figsize=(3 * len(task['train']), 6)) for i, pair in enumerate(task['train']): draw(pair['input'], axes[0][i], f'train {i} in') draw(pair['output'], axes[1][i], f'train {i} out') plt.tight_layout() plt.show()

A window opens with the train pairs drawn in the standard ARC palette. Close it to end the program.
