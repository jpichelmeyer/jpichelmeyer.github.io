Every earlier lesson gave the agent a way to think about a task. Meta-reasoning is thinking about that thinking: choosing which method to use, noticing whether it is working, deciding when to switch or stop, and learning which methods suit which problems. It is the Monitor from week 1 grown into a full reasoner, and it is where your semester agent becomes one agent instead of a drawer of separate tricks.

Part 1. Reasoning About Reasoning

Meta-reasoning. The meta level holds a model of the object level's strategies and uses it the way the object level uses a model of the task.

Goel and Joyner make a point that is easy to miss: meta-reasoning uses the same methods as reasoning. Choosing a strategy can be classification ("this looks like a tiling task"), case-based reasoning ("last time a task like this, analogy worked"), planning ("first try the cheap specialists, then search"), or learning by correcting mistakes ("that strategy failed; why?"). The only difference is what the knowledge is about: the agent's own methods instead of the world.

Three questions the meta level keeps asking:

  • Selection: given what I notice about this problem and what I know about my strategies, which should I try first?
  • Monitoring: is the current strategy making progress? Is its answer any good?
  • Learning about myself: after each problem, update what I believe about each strategy's reliability and cost.
Human cognition connection

Robert Siegler's studies of children learning arithmetic (the overlapping waves model, 1996) found that children do not switch suddenly from one strategy to a better one. They keep several strategies (counting on fingers, counting on from the larger number, retrieving the answer) and choose among them problem by problem, with the better strategies gradually winning as experience shows which works. People also monitor their own memory: the feeling of knowing (Joseph Hart, 1965) predicts whether you will recognize an answer you cannot recall. This week's Bennett reading suggests that primates evolved brain areas that model the brain's own simulations; the McShane reading shows an agent that can explain its reasoning because it records metadata about that reasoning as it goes.

Part 2. A Meta-Reasoning Agent

The agent solves mazes with two strategies: greedy search (cheap, but sometimes takes a long detour) and breadth-first search (expensive, always shortest). Its meta level keeps a record of each strategy's reliability and cost, picks the one with the best expected value, monitors the answer, and switches if the answer is unacceptable.

strategy_agent.py: two strategies Python
def greedy(grid, start, goal, budget): """Fast and focused, but can wander into dead ends and long detours.""" h = lambda x: abs(x[0] - goal[0]) + abs(x[1] - goal[1]) frontier, seen, work = [(h(start), start, [start])], {start}, 0 while frontier and work < budget: _, cell, path = heapq.heappop(frontier) work += 1 if cell == goal: return path, work for n in neighbours(grid, cell): if n not in seen: seen.add(n) heapq.heappush(frontier, (h(n), n, path + [n])) return None, work def breadth_first(grid, start, goal, budget): """Slow but thorough: always finds the shortest path if there is one.""" frontier, prev, work = deque([start]), {start: None}, 0 while frontier and work < budget: cell = frontier.popleft() work += 1 if cell == goal: path = [] while cell: path.append(cell) cell = prev[cell] return path[::-1], work for n in neighbours(grid, cell): if n not in prev: prev[n] = cell frontier.append(n) return None, work STRATEGIES = {'greedy': greedy, 'breadth-first': breadth_first}
strategy_agent.py: the meta level Python
class MetaReasoner: """The meta level: a model of its own strategies (how often each one gives an acceptable answer, and how much work it costs), used to choose, to monitor, and to switch.""" def __init__(self): self.stats = {s: {'tries': 1, 'good': 1, 'work': 50} for s in STRATEGIES} def expected_value(self, s): st = self.stats[s] return st['good'] / st['tries'] * 100 - st['work'] / st['tries'] * 0.5 def acceptable(self, path, start, goal): """Monitoring: is the answer good enough? (not a huge detour)""" straight = abs(start[0] - goal[0]) + abs(start[1] - goal[1]) return path is not None and len(path) - 1 <= 1.3 * straight def solve(self, grid, start, goal): order = sorted(STRATEGIES, key=self.expected_value, reverse=True) log = [] for s in order: path, work = STRATEGIES[s](grid, start, goal, budget=200) ok = self.acceptable(path, start, goal) or (s == order[-1] and path) st = self.stats[s] st['tries'] += 1 st['work'] += work st['good'] += bool(ok) log.append(f'{s} ({work} steps of work): ' + ('accepted' if ok else 'no path' if path is None else f'path of {len(path) - 1} rejected as a detour')) if ok: return log return log + ['gave up']

The meta level started optimistic about greedy (cheaper, equally reliable as far as it knew), used it on maze 1, and switched to breadth-first when greedy's answer on maze 2 failed the quality check. Then something instructive happened: greedy never got a second chance. One failure dropped its expected value below breadth-first's, and the agent kept using the expensive strategy on mazes greedy would have solved for a third of the work. That is the exploration versus exploitation trade-off, and a good meta level needs a policy for it (an exercise below).

Part 3. Your Agent, Integrated

Here is the payoff of the semester. Every ARC specialist from earlier lessons becomes a strategy under one meta level. The meta level perceives a few cheap features of the task, puts the specialists those features trigger first (configuration when the output is a multiple of the input size, truth tables when it is half, completion when a mask colour is present...), orders the rest by their track record, runs them under a time budget, verifies every candidate on all train pairs, and keeps up to two distinct test answers.

The integrated ARC agent. Every specialist is an object-level strategy; the meta level chooses, monitors, and keeps score.

arc_meta.py: triggers Python
def features(t): """What the meta level notices about a task before choosing a strategy.""" ps = t['train'] same = all(dims(p['input']) == dims(p['output']) for p in ps) hi, wi = dims(ps[0]['input']) ho, wo = dims(ps[0]['output']) return {'same_size': same, 'bigger': ho * wo > hi * wi, 'smaller': ho * wo < hi * wi, 'multiple': ho % hi == 0 and wo % wi == 0 and (ho, wo) != (hi, wi), 'halves': (ho, wo) in [(hi, wi // 2), (hi // 2, wi), (hi, (wi - 1) // 2), ((hi - 1) // 2, wi)], 'mask': bool(set.intersection(*(colors(p['input']) - colors(p['output']) for p in ps))), 'repeats': len({str(p['output']) for p in ps}) < len(ps)} SPECIALISTS = { # name: (function, trigger) 'configuration': (sp_configure, lambda f: f['multiple']), 'truth tables': (sp_logic, lambda f: f['halves']), 'completion': (sp_complete, lambda f: f['mask']), 'classification': (sp_classify, lambda f: f['repeats']), 'local rules': (sp_rules, lambda f: f['same_size']), 'priors': (sp_priors, lambda f: f['same_size']), 'events': (sp_events, lambda f: f['same_size']), 'analogy': (sp_analogy, lambda f: f['same_size']), 'concepts': (sp_concepts, lambda f: f['same_size']), 'scripts': (sp_script, lambda f: f['same_size']), 'explanation': (sp_ebl, lambda f: True), 'repair': (sp_repair, lambda f: True), 'program search': (sp_search, lambda f: True), }
arc_meta.py: the meta level Python
class MetaLevel: def __init__(self): self.record = {name: [1, 2] for name in SPECIALISTS} # [successes+1, tries+2] def order(self, f): """Triggered specialists first; within each group, best track record first.""" rate = lambda n: self.record[n][0] / self.record[n][1] return sorted(SPECIALISTS, key=lambda n: (not SPECIALISTS[n][1](f), -rate(n))) def verify(self, fn, t): try: return all(fn(p['input']) == p['output'] for p in t['train']) except Exception: return False def solve(self, t, budget=2.0): """Run specialists in order; keep every verified solver; stop with two distinct test answers or when the time budget is spent.""" f, start, answers, credit = features(t), time.time(), [], [] for name in self.order(f): if time.time() - start > budget: break fn_, trig = SPECIALISTS[name] try: candidates = fn_(t) except Exception: candidates = [] self.record[name][1] += 1 for fn in candidates: if self.verify(fn, t): try: guess = [fn(p['input']) for p in t['test']] except Exception: continue if guess not in answers: answers.append(guess) credit.append(name) self.record[name][0] += 1 if len(answers) >= 2: break return answers[:2], credit[:2]

Which specialist gets credit on the training set. Program search gets the most credit partly because it is a general fallback.
The evaluation set, on the same scale. The specialists that transfer are the ones built on a general idea (constraints, truth tables, configuration), not the ones that memorized a few primitives.

Two numbers to sit with. On the training set, the integrated agent solves 88 tasks, more than any single lesson's specialist, because the meta level lets each specialist work where it fits. On the harder evaluation set it solves 36, and the credit list changes completely: program search, the champion on training tasks, gets no credit at all (on its own it solves just one evaluation task), while completion, truth tables, and configuration carry the load. Methods built around a general idea transfer; methods built around a fixed list of primitives do not. (Times vary by machine: with a 2-second budget per task, a slower computer may try fewer specialists and score a little lower.)

SAM lens

This lesson is the Monitor becoming a meta level: it perceives the agent's own strategies (their triggers, costs, and records), decides among them, and acts by running, switching, and stopping them. Its track record is meta-Memory. Everything else in SAM stays as it was; the meta level is SAM applied to the agent itself, as promised in week 1.
