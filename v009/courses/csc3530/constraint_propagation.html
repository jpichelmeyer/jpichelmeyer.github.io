Many problems are best described not by steps but by constraints: conditions that any acceptable answer must satisfy at once. Constraint propagation uses each constraint to rule out possibilities, and every possibility ruled out may let another constraint rule out more, until the answer is pinned down or only a few options remain. It is how you solve a Sudoku, how perception settles on one reading of an ambiguous picture, and how an ARC agent can fill in a pattern that has been partly painted over.

Part 1. Variables, Domains, Constraints

A constraint problem has variables (the cells of a Sudoku), each with a domain of possible values (1 to 4), and constraints relating them (no two cells in a row, column, or box are equal). Propagation repeatedly removes from a variable's domain any value that cannot be part of a solution given its neighbours' domains. This is arc consistency; the standard algorithm is AC-3 (Mackworth, 1977).

One propagation step. Cell (1,1) sees a 2 in its row, a 3 in its column, and a 1 in its box, so only 4 remains. That new fact constrains other cells in turn.

Propagation is not search. It never guesses; it only deletes what is impossible. Sometimes that is enough to solve the whole problem. When it is not, the agent guesses one variable, propagates the consequences, and backs up if it reaches a contradiction. Good propagation makes the guessing rare.

Constraint propagation in perception.
Human cognition connection

This week's Bennett reading lists peculiar properties of human perception: we fill in missing parts, we see only one interpretation at a time of an ambiguous figure (the Necker cube, the duck-rabbit), and once we have seen a hidden figure we cannot unsee it. Each is what you would expect from a system that settles on an interpretation consistent with all its constraints at once. Hermann von Helmholtz called it unconscious inference. In knowledge-based AI, David Waltz's line-labeling program (1975) showed the machine version: label every line in a drawing of blocks as convex, concave, or an occluding edge, and let the junctions eliminate inconsistent labels.

sudoku_agent.py: constraints Python
def peers(cell): """Cells that must differ from this one: same row, column, or 2x2 box.""" r, c = cell return {(rr, cc) for rr, cc in cells if (rr, cc) != cell and (rr == r or cc == c or (rr // 2, cc // 2) == (r // 2, c // 2))}
sudoku_agent.py: propagation Python
def propagate(domain, verbose=True): """AC-3 style: whenever a cell is down to one value, remove that value from every peer. Repeat until nothing changes.""" queue = [cell for cell in cells if len(domain[cell]) == 1] while queue: cell = queue.pop(0) (v,) = domain[cell] for p in peers(cell): if v in domain[p]: domain[p] = domain[p] - {v} if not domain[p]: return False # contradiction if len(domain[p]) == 1: if verbose: print(f' {p} forced to {next(iter(domain[p]))}') queue.append(p) return True
sudoku_agent.py: search, only if propagation runs out Python
def solve(domain, depth=0): """Propagate; if that is not enough, guess the most constrained cell and propagate again (backtracking on contradiction).""" if not propagate(domain, verbose=depth == 0): return None open_cells = [c for c in cells if len(domain[c]) > 1] if not open_cells: return domain cell = min(open_cells, key=lambda c: len(domain[c])) for v in sorted(domain[cell]): trial = {k: set(s) for k, s in domain.items()} trial[cell] = {v} print(' ' * depth + f' guess {cell} = {v}') result = solve(trial, depth + 1) if result: return result return None solution = solve(domain) for r in range(4): print(' '.join(str(next(iter(solution[(r, c)]))) for c in range(4)))

Part 3. A Taste of ARC: Filling In What Must Be There

A family of ARC tasks shows a regular pattern with part of it painted over, and asks for the hidden part. That is filling in, exactly as Bennett describes perception doing it. Two kinds of constraint cover most of these tasks: the pattern repeats with some period, or it is mirror symmetric. Either one groups cells into classes that must share a colour, and the visible cells of a class propagate their colour to the hidden ones.

Task 0dfd9992. A repeating pattern with black patches painted over it. The output is the pattern without the patches.
arc_complete.py: two families of constraints Python
def period_classes(h, w, p, q): """Constraint: the picture repeats every p rows and q columns, so all cells with the same (row mod p, col mod q) must have the same colour.""" return lambda r, c: (r % p, c % q) def mirror_classes(h, w, p, q): """Constraint: the picture is symmetric left-right and top-bottom (about its centre, offset by p and q), so mirror cells match.""" def key(r, c): rr, cc = min(r, h - 1 - r + p), min(c, w - 1 - c + q) return (rr, cc) return key
arc_complete.py: propagation, with contradiction detection Python
def complete(grid, mask, family, p, q): """Group cells by the constraint; each group must share one colour. Known cells propagate their colour to masked cells in the same group. Fails on a contradiction or if some masked group has no known cell.""" h, w = dims(grid) key = family(h, w, p, q) value = {} for r in range(h): for c in range(w): if grid[r][c] != mask: k = key(r, c) if value.setdefault(k, grid[r][c]) != grid[r][c]: return None # contradiction: constraint is wrong out = [row[:] for row in grid] for r in range(h): for c in range(w): if grid[r][c] == mask: k = key(r, c) if k not in value: return None # nothing to propagate from out[r][c] = value[k] return out def masked_box(grid, mask): cells = [(r, c) for r, row in enumerate(grid) for c, v in enumerate(row) if v == mask] rs, cs = [r for r, _ in cells], [c for _, c in cells] return min(rs), min(cs), max(rs), max(cs)

The agent does not know which constraint holds. It tries the simplest first (small periods, then mirror symmetries) and rejects any constraint that produces a contradiction, meaning two visible cells in the same class with different colours. A contradiction is information: it proves that constraint false.

arc_complete.py: try constraints from simplest to most complex; find the mask colour Python
def solve(grid, mask, want_patch): """Try the simplest constraints first: small periods, then mirror symmetries. Return the whole completed grid, or just the hidden patch.""" h, w = dims(grid) periods = sorted(((p, q) for p in range(1, h) for q in range(1, w)), key=lambda pq: pq[0] * pq[1]) options = [(period_classes, p, q) for p, q in periods] options += [(mirror_classes, p, q) for p in range(-3, 4) for q in range(-3, 4)] for family, p, q in options: full = complete(grid, mask, family, p, q) if full is not None: if want_patch: t, l, b, r = masked_box(grid, mask) full = [row[l:r + 1] for row in full[t:b + 1]] return full, f'{family.__name__} {(p, q)}' return None, None def mask_color(task): """The colour that hides things: present in every input, absent from outputs.""" cands = set.intersection(*(colors(p['input']) - colors(p['output']) for p in task['train'])) return min(cands) if cands else 0

Getting that kind of detail right is what keeps an agent honest.

SAM lens

Constraint propagation can live in two places. In the Perceptor, it completes and disambiguates what was seen (filling in the hidden patch). In the Decider, it prunes the space of possible answers before search (the TaskFrame invariants from week 2 are constraints). Contradiction detection is a Monitor signal: it says "this hypothesis is false," which is often more useful than "this one might be true."
