MultiPipeline EEG Tool

Motivation

Approach

For a given participant:

  1. Segment an EEG stream into a specified number of windows (say 30 windows) and with a specified overlap (say 10%)
  2. Windows are matricies with shape (number_of_samples, number_of_channels)
  3. The set of eeg windows (matrices) is fed into a set of pipelines
  4. Each pipeline processes the windows according to its focus, but all pipelines return a cluster id for each window
  5. The resulting vectors of cluster ids (one such vector per pipeline) are compared pairwise using normalized mutual information (NMI)

Notes:

  • Pipelines had broad categories: topological, band, autoencoder
  • Some pipelines generated a feature set per window, then applied dimension reduction techniques before clustering.
  • Many combinations of pipelines with slight variations due to array of dimension reduction and clustering algorithms.
