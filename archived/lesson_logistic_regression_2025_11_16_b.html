▶ 2. The Logistic Function (ISL 4.2)
8 minutes
The Logistic Function:
p(X) = L / (1 + exp(-k(X - x₀)))
  • L: Maximum value (typically 1 for probability)
  • x₀: Midpoint where p(x₀) = L/2 (decision boundary when L=1)
  • k: Steepness/slope parameter (larger |k| = steeper S-curve)
  • Always outputs values in (0, L), making it perfect for probabilities
  • S-shaped curve: gradual transitions, never linear at extremes
Try this:
  • Set model to "Logistic Only" above
  • Adjust k: see how steepness changes the decision boundary
  • Adjust x₀: move the decision boundary left/right
  • Notice: predictions always stay between 0 and 1
▶ 3. Estimating Parameters: Maximum Likelihood (ISL 4.3)
10 minutes
Why not least squares?
  • For binary outcomes, we use maximum likelihood estimation (MLE)
  • Goal: find parameters that maximize the probability of observing our data
The Likelihood Function:
L(β) = ∏ᵢ p(xᵢ)^yᵢ · (1 - p(xᵢ))^(1-yᵢ)
  • Product over all observations
  • If yᵢ = 1: contribute p(xᵢ) to likelihood
  • If yᵢ = 0: contribute (1 - p(xᵢ)) to likelihood
Log Likelihood (easier to work with):
ℓ(β) = ∑ᵢ [yᵢ log(p(xᵢ)) + (1-yᵢ) log(1-p(xᵢ))]
  • Maximize log likelihood = minimize negative log likelihood
  • Cross-entropy loss = negative log likelihood / n
  • This is what you see as "Log Loss" above
Interactive Exploration:
  • Set model to "Both Models" to compare
  • Adjust parameters to minimize log loss
  • Notice: log loss heavily penalizes confident wrong predictions
  • If p(x)→0 but y=1, or p(x)→1 but y=0, loss → ∞
▶ 4. Interpretation & Decision Boundaries
5 minutes
Making Predictions:
  • Logistic regression gives us p(Y=1|X) - the probability of class 1
  • Decision rule: predict class 1 if p(X) > threshold (usually 0.5)
  • The decision boundary is where p(X) = 0.5
  • In our simple model: decision boundary at x = x₀
Odds and Log-Odds:
odds = p/(1-p), log(odds) = β₀ + β₁X
  • The log-odds is linear in X
  • This is why it's called logistic regression
  • Coefficient β₁: one unit increase in X multiplies odds by exp(β₁)

▶ 5. Summary & Extensions
2 minutes
Key Takeaways:
  • ✓ Logistic regression models probabilities for binary outcomes
  • ✓ Uses logistic function to constrain predictions to [0,1]
  • ✓ Parameters estimated via maximum likelihood (minimize log loss)
  • ✓ Interpretable via odds ratios and decision boundaries
Extensions (ISL Chapter 4):
  • Multiple logistic regression: p(X) = logistic(β₀ + β₁X₁ + β₂X₂ + ...)
  • Multi-class: multinomial logistic regression (softmax)
  • Regularization: L1 (lasso) and L2 (ridge) penalties
  • Alternative: Linear/Quadratic Discriminant Analysis (LDA/QDA)
